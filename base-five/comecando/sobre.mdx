A **Base Five** é uma base completa de servidor FiveM construída sobre o framework **vRP**, distribuída pela loja **Five Network**. Ela já vem com dezenas de recursos integrados, banco de dados estruturado e interfaces (NUI) modernas em React.

---

## O que vem na base

A base é organizada em pastas bracketadas que o `server.cfg` carrega em ordem:

| Pasta | Conteúdo |
| --- | --- |
| `resources/vrp/` | Framework core (carrega primeiro). |
| `resources/[system]/` | Infraestrutura de terceiros: `oxmysql`, `ox_lib`, `ox_target`, `ox_doorlock`, `pma-voice`, `PolyZone`, `sleepless_interact`, `screenshot-basic`, `sessionmanager`, `freecam`, `loading`, `mugshot` e `sounds`. |
| `resources/[weapons]/` | Armas e assets streamados: `WEAPON_BRICK`, `WEAPON_KATANA`, `WEAPON_METAS`, `WEAPON_SHOES` e `WEAPON_SKINS`. |
| `resources/[scripts]/` | Scripts de gameplay (HUD, inventário, MDT, prisão, propriedades, etc.). |
| `resources/[five]/` | Recursos `five-*` próprios da base (banco, veículos, empregos, criação, etc.). |
| `[smartphone]/` | `lb-phone` e bibliotecas. |

## Anatomia de um recurso `five-*`

```text
five-<nome>/
  fxmanifest.lua          -- declara dependências, scripts e ui_page
  config/                 -- configuração em Lua (a parte que você mais edita)
  server-side/            -- lógica de servidor (vRP/oxmysql)
  client-side/            -- lógica de cliente e ponte com a NUI
  web-side/  (ou web/)    -- interface React (opcional)
  stream/                 -- assets streamados (opcional)
```

<Tip>
  Na prática, **90% da customização do dia a dia acontece nos arquivos `config/*.lua`** de cada recurso (preços, localizações, comandos, permissões, cores e webhooks). Cada página da seção **Recursos** detalha essas opções.
</Tip>

## Convenções importantes

<AccordionGroup>
  <Accordion title="Passport e source" icon="id-card">
    **Passport** é o ID do personagem (usado nas funções `vRP.*`). **source** é o ID de rede do jogador.
  </Accordion>

  <Accordion title="Cores / tema" icon="palette">
    Muitos recursos têm um `ThemeColor`, mas a global `Theme.main` (em `vrp/config/Global.lua`) tem **prioridade** quando definida.
  </Accordion>

  <Accordion title="CDN de imagens" icon="image">
    Itens e alguns assets usam URLs externas (`ItemsURL`, `AssetsUrl`). Você pode apontar para o seu próprio host.
  </Accordion>

  <Accordion title="Nomes de pasta bracketados" icon="folder">
    `[five]`, `[scripts]` são literais; sempre cite entre aspas em comandos de terminal.
  </Accordion>
</AccordionGroup>

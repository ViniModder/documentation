Referência das funções reais registradas na interface `vRP` (Proxy, lado servidor), agrupadas por área. Todas extraídas de `resources/vrp/modules/*.lua`. Obtenha a interface com:

```lua
local Proxy = module("vrp","lib/Proxy")
vRP = Proxy.getInterface("vRP")
```

<Note>
  **Convenção:** `Passport` é o id do personagem (não o `source`). `source` é o id de rede do player.
</Note>

---

    | `vRP.Phone(Passport)` | Número de telefone (gera e persiste se não existir). |

## Aliases de compatibilidade que funcionam

Existem e apontam para funções reais (mas prefira os nomes oficiais acima):

`vRP.getUserId` → `Passport`; `vRP.getUserSource` → `Source`; `vRP.query` → `Query`; `vRP.getUserIdentity` → `Identity`; `vRP.userInventory` → `Inventory`; `vRP.giveInventoryItem` → `GiveItem`; `vRP.tryGetInventoryItem` → `TakeItem`; `vRP.removeInventoryItem` → `RemoveItem`; `vRP.getInventoryItemAmount` → `InventoryItemAmount`; `vRP.checkMaxItens` → `MaxItens`; `vRP.addBank`/`giveBankMoney` → `GiveBank`; `vRP.removeBankMoney` → `RemoveBank`; `vRP.getBank` → `GetBank`; `vRP.tryPayment`/`tryFullPayment` → `PaymentFull`; `vRP.hasPermission` → `HasPermission`; `vRP.getHealth` → `GetHealth`.

<Warning>
  **Aliases quebrados (NÃO use, apontam para função inexistente):** `vRP.setWeight`, `vRP.registerDrivers`, `vRP.userPremium`, `vRP.steamPremium`, `vRP.falseIdentity`, `vRP.getFines`, `vRP.addFines`, `vRP.delFines`, `vRP.generateStringNumber`.
</Warning>

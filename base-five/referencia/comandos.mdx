## Como usar

Cada recurso registra seus próprios comandos. Muitos comandos exigem permissão de grupo vRP (`Admin`, `Tuning`, etc.).

<Info>
  A hierarquia vRP funciona de forma invertida: **nível menor = mais privilégio** (nível 1 é o mais alto).
</Info>

<Note>
  Esta página cobre apenas os recursos da pasta `[five]`. Os comandos dos recursos de `[scripts]` — incluindo os quase 60 comandos administrativos do `admin` (`/god`, `/tpto`, `/money`, `/skin`, `/spectate`…) — estão documentados na própria página de cada script: [admin](/base-five/scripts/admin), [hud](/base-five/scripts/hud), [player](/base-five/scripts/player), [party](/base-five/scripts/party), [inventory](/base-five/scripts/inventory), [pages](/base-five/scripts/pages), [inspect](/base-five/scripts/inspect), [halloween](/base-five/scripts/halloween), [taximeter](/base-five/scripts/taximeter), [fuelstations](/base-five/scripts/fuelstations) e [wc_emotes_v7](/base-five/scripts/wc_emotes_v7).
</Note>

| `/prisaoadm` / `/remprisaoadm` | Prison (6) | Prende/solta na ilha. |
| `/verificarprisao` | Check (6) | Mostra a prisão ativa. |
| `/toggleamarrar` | N/A | Liga/desliga a HUD de punição própria. |
| `/ban` / `/unban` | Ban (4) | Ban permanente / remove. |
| `/tempban` | TempBan (4) | Ban temporário (tempo). |

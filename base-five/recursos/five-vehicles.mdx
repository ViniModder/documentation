title: "five-vehicles"
description: "Sistema completo de veículos da Five Network: concessionárias, garagens, aluguel, mecânicas/tunagem, IPVA, apreensão, empréstimo e venda de veículos entre jogadores."
---

O **five-vehicles** é o recurso central de veículos do servidor. Ele controla todo o ciclo de vida de um veículo: compra/aluguel em concessionárias, guarda e retirada em garagens (públicas, de facção/serviço, aéreas e aquáticas), aplicação e cobrança de modificações nas mecânicas, sistema de IPVA, status especiais (apreendido, furtado, desmanchado) e ferramentas administrativas para gerar, renovar e remover veículos de personagens.

O cadastro de veículos (a `vehlist`) e a maioria das garagens são gerenciados em tempo real (em jogo) pelos comandos de administração, persistidos em banco de dados e sincronizados com os clientes via StateBag, não exigindo reinício do recurso. A UI é uma aplicação React (NUI) em `web-side/`.

## Configuração

<AccordionGroup>
  <Accordion title="config/general.lua — Configurações gerais" icon="sliders">
    ```lua
    vehiclesVerbose = false   -- mensagens de inicialização no console (debug)
    ThemeColor = "#0143bb"    -- cor da UI (Theme.main em Global.lua tem prioridade)
    debugMode = false         -- mensagens de debug no client
    fixed_rental_plates = true
    -- Gera placas PERMANENTES para veículos de serviço/aluguel (garagens 'SERVICE').
    -- Permite salvar tunagem e porta-malas entre as retiradas. Se false, placa aleatória a cada retirada.
    vehMenu = { enabled = true, key = 'M' }  -- menu de veículos (segure M)
    autoLockAIVehicles = true -- impede o uso de veículos de NPC (ficam trancados)
    ```
  </Accordion>

  <Accordion title="config/commands.lua — Comandos e impostos" icon="terminal">
    Cada comando tem `enabled`, `name` e `permission` (qualquer permissão da tabela libera).

    ```lua
    commands = {
        ['spawnVehicles']       = { enabled = true, name = 'car',    permission = {'Admin'} },
        ['despawnVehicles']     = { enabled = true, name = 'dv',     permission = {'Admin','Militar','Civil','CORE','BOPE','PRF'} },
        ['despawnAreaVehicles'] = { enabled = true, name = 'dvarea', maxRadius = 100, permission = {'Admin'} },
        ['fixVehicles']         = { enabled = true, name = 'fixar',  permission = {'Admin'} },
        ['stockManager']        = { enabled = true, name = 'vstock', permission = {'Admin'} },
        ['characterVehManager'] = { enabled = true, name = 'vmanager', permission = {'Admin'} },
        ['garageManager']       = { enabled = true, name = 'gmanager', permission = {'Admin'} },
    }
    ```

    ```lua
    vehicleTaxes = {
        durationInDays = 7,       -- a cada quantos dias o IPVA vence
        percentFromPrice = 0.05   -- valor do IPVA = 5% do preço do veículo
    }
    borrowSystem = { enabled = false, ... }  -- empréstimo de chave pela garagem
    sellSystem   = { enabled = false, ... }  -- venda de veículos entre personagens
    logsWebhooks = { ... }  -- webhook do Discord por tipo de log (vazio = sem log)
    ```
  </Accordion>

  <Accordion title="config/dealership.lua — Concessionárias" icon="store">
    ```lua
    testDrive = {
        payment = 200,                               -- valor do test drive (0 = grátis)
        coords = {-1700.43,-2934.25,13.95,239.57},   -- teleporte do test drive
        time = 120,                                  -- tempo limite (segundos)
        plate = 'PDMSPORT'
    }
    infiniteStock = true   -- true: estoque infinito | false: usa five_vehicles_stock e /vstock
    permissionDiscounts = { ['owner'] = 50 }  -- desconto por permissão (%) na compra
    sellBack = { enabled = true, percentFromPrice = 0.2, ... }  -- revenda à concessionária (20%)
    ```

    Cada concessionária é um bloco em `dealerships` com `coords`, `permission` (nil = livre), `blips`, `modelViewer` (ped \+ veículo exibido) e `disabledCategories`. Duplique o bloco para criar mais.
  </Accordion>

  <Accordion title="config/garages.lua — Garagens" icon="warehouse">
    `garages_types` define quais categorias aparecem em cada tipo de garagem (`NORMAL`, `PROPERTY`, `AIR`, `WATER`). Cada garagem em `garages`:

    ```lua
    {
        name = 'Garagem',
        permission = nil,          -- string, tabela {'p1','p2'} ou nil (pública)
        payment = 500,             -- (opcional) taxa de retirada; 0/ausente = grátis
        type = 'NORMAL',           -- NORMAL | PROPERTY | AIR | WATER | SERVICE
        open = {101.04,-1073.62,29.38,261.67},  -- ponto de acesso
        spawns = { {105.07,-1077.14,29.2,339.59} },  -- vagas de spawn
        blip = { enabled = true, icon = 357, color = 0, size = 0.5 },
        marker = { icon = 36, color = {255,255,255,255}, size = 0.8 }
    }
    ```

    Garagens de serviço/aluguel usam `type = 'SERVICE'` \+ `vehicles = { ['index'] = preço }` (frota fixa).
  </Accordion>

  <Accordion title="config/mechanics.lua — Mecânicas" icon="wrench">
    A mecânica só funciona se o `five-bennys` NÃO estiver iniciado. `DefaultTunnings` é a tabela de preços (cores, luzes, performance, rodas, insulfilm, etc.). Cada mecânica em `mechanics`:

    ```lua
    ['mechanicName'] = {
        coords = { {48.39,-878.02,30.37,151.54} },
        blips = { enabled = true, id = 523, color = 61, size = 0.55, name = 'Mecânica' },
        autoMode = true,            -- sistema de pedidos/orçamento
        permission = 'Ballas',      -- permissão dos mecânicos
        disablePerfTunnings = false,
        onlyPerfTunnings = false,
        tunnings = DefaultTunnings,
    }
    ```
  </Accordion>

  <Accordion title="config/vehicles.lua — Categorias" icon="list">
    Define apenas as `categories` (chave =\> rótulo). A `vehlist` é **dinâmica** (gerenciada por `/gmanager`, persistida em `five_vehicles_registered`).
  </Accordion>

  <Accordion title="config/config.ui.js — Imagens da UI" icon="image">
    ```js
    window.VEHICLE_IMAGE_URL = "https://pub-645a02b858fe4d66bc9365f1de3ee401.r2.dev/Cars";
    // URL base das imagens: {URL}/{index}.png. Troque pela sua CDN.
    ```
  </Accordion>
</AccordionGroup>

## Comandos

Os comandos administrativos abaixo são definidos em `config/commands.lua`.

| Comando | Permissão | Descrição |
| --- | --- | --- |
| `/car <modelo>` | Admin | Spawna um veículo pelo index do modelo. |
| `/dv` | Admin e forças | Remove o veículo mais próximo. |
| `/dvarea` | Admin | Remove veículos numa área (raio ~50). |
| `/fixar` | Admin | Conserta o veículo. |
| `/vstock` | Admin | Gerenciador de estoque das concessionárias. |
| `/vmanager <id>` | Admin | Gerenciador de veículos do personagem. |
| `/gmanager` | Admin | CRUD de garagens e de veículos (`vehlist`). |
| `/pedidos <mecanica>` | permissão da mecânica | Mecânico atende pedidos de tunagem. |

<Info>
  Keybinds: trancar/destrancar veículo = `L` (remapeável); menu do veículo = `M` (`general.lua`).
</Info>

## Exports

O recurso expõe dezenas de exports server-side, entre eles:

- **Consulta:** `getVehicleInfo(hashOrIndex)`, `getVehicleList()`, `getVehicleIdentity(plate)`, `getVehicleData(plate)`, `getCharacterVehicles(characterId, includeBorrowed)`.
- **Criação:** `generateVehicle(characterId, model, customColors, customPlate)`, `giveVehicle(characterId, model)` (retorna `{ok, plate|error}`), `generateRentalVehicle(...)`.
- **Manutenção:** `updateRentalVehicleDays`, `updateVehicleTax`, `updateVehicleStatus`, `updateVehicleMods`, `changeVehiclePlateIRT`, `transferVehicle`, `deleteVehicle`.
- **Garagens:** `insertGarage(garage)`, `removeGarage(gId)`.

Client: `getVehicleInfo`, `getVehicleList`, `renderGarage`, `unrenderGarage`.

## Eventos

- `five-vehicles:vehicleCreated` (server): disparado quando um veículo é criado. Args: `plate, netId`.
- Eventos de compatibilidade com a antiga API "garages": `garages:Key`, `garages:Delete`, `garages:ChangePlate`, etc.

<Note>
  As ações de gameplay (comprar, alugar, guardar/retirar, tunar) são chamadas via **Tunnel** (tabela `SV`), não por net events públicos.
</Note>

## Customização

### Adicionar/editar veículos (vehlist)

Não edite `config/vehicles.lua` manualmente, use **`/gmanager`** (aba Veículos) em jogo. Campos persistidos: `spawn` (index, único), `name`, `category`, `paymentType` (`primary`/`secondary`=diamantes), `price`, `gemstone`, `weightTrunk`/`weightGloves`, `class`, `mode`, `outDealership`. As imagens vêm de `config.ui.js` → `{VEHICLE_IMAGE_URL}/{spawn}.png`.

### Adicionar concessionárias / garagens / mecânicas

- **Concessionárias:** duplique um bloco em `dealerships` (config/dealership.lua).
- **Garagens:** bloco estático em `garages` ou (recomendado) `/gmanager` em jogo.
- **Mecânicas:** entradas em `mechanics` (config/mechanics.lua). Lembre: `five-bennys` ativo desativa a mecânica interna.

### Limites de veículos por jogador

Hardcoded em `server-side/framework.lua` (`permissionLimits`): padrão 10; `vip1`=20, `vip2`=30, `vip3`=40, `admin`=50.

### Multas por status (server-side/framework.lua)

Apreendido = 25% do preço, furtado = 10%, desmanchado = 30%, IPVA atrasado = `vehicleTaxes.percentFromPrice`.

<Tip>
  Prefira gerenciar veículos e garagens em jogo via `/gmanager`, evitando reinício do recurso.
</Tip>

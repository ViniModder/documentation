---

O **five-modules** é o agregador de funcionalidades globais do cliente. **Não tem NUI nem pasta `config/` própria** (as configs são tabelas Lua nos próprios arquivos ou herdadas de `@vrp/config/*`).

## Funcionalidades

<CardGroup cols={2}>
  <Card title="Mundo vivo" icon="earth-americas">
    Densidade de veículos/pedestres, spawn de polícia/trens/barcos, dispatch, limpeza de entidades, Ilha, IPLs, teletransportes e blackout (apagão).
  </Card>

  <Card title="Clima/relógio" icon="cloud-sun">
    A cada 1s aplica clima/hora lendo o estado `cw_override` (do `five-weather`) com prioridade sobre o `GlobalState`.
  </Card>

  <Card title="Interações" icon="hand-pointer">
    Registra via `ox_target` quase todas as ações da cidade (abastecer, porta-malas, reboque, desmanche, ações médicas/policiais, etc.).
  </Card>

  <Card title="Auxiliares" icon="wrench">
    Academia, macas, cadeiras, noclip, helicâmera, zoom, dano veicular, blips, peds estáticos e expediente.
  </Card>
</CardGroup>

## Configuração

Sem arquivo de config próprio. Principais tabelas:

<AccordionGroup>
  <Accordion title="@vrp/config/Global.lua — NPCSystem (mundo vivo)" icon="earth-americas">
    ```lua
    NPCSystem = {
        DefaultVehicleDensity = 0.1,   -- densidade de veículos NPC (0.0-1.0)
        DefaultPedDensity = 1.0,       -- densidade de pedestres NPC
        SpawnVehicles = false, SpawnTrains = true, SpawnBoats = true,
        SpawnPoliceVehicles = false, AllowArmedPeds = true,
        DispatchServices = false,      -- EnableDispatchService
        AreaOverrides = {              -- densidade própria por raio
            { x = 195.24, y = -937.37, z = 29.42, radius = 150, pedDensity = 0.0, vehicleDensity = 0.0 },
        },
    }
    ```
  </Accordion>

  <Accordion title="shared-side/academy.lua — Academy" icon="dumbbell">
    ```lua
    { ["Target"] = vec3(...), ["Coords"] = vec4(...), ["Anim"] = "malhar2" }  -- 18 pontos
    ```
  </Accordion>

  <Accordion title="Outras tabelas editáveis" icon="list">
    Outras tabelas editáveis (no respectivo arquivo): `TELEPORT`/`ISLAND`/`IPL_LIST` (`client-side/core.lua`), `Hospitals`/`BedModels` (`beds.lua`), `Chairs` (`chairs.lua`), `Fuels`/`Dismantle`/`Tyres` (`interactions.lua`), `List` de peds (`peds.lua`), `Services` (`service.lua`), `blipsOnMap` (`blips.lua`). Valores fixos no código: pesos da academia por VIP (Ouro\+60/Prata\+40/Bronze\+20, base 75) e cobrança do centro médico (`server-side/target.lua`); blackout = 1800s \+ item `encryptedkey` \+ ≥10 policiais.
  </Accordion>
</AccordionGroup>

## Eventos

Os eventos abaixo coordenam expediente, blackout e as ações auxiliares registradas via tunnel/target.

| Lado | Eventos |
| --- | --- |
| Servidor | `target:Repose`, `target:Service` (alterna expediente), `target:Blackout`. |
| Tunnel `target` | `Core.Academy`, `Core.AcademyWeight`, `Core.CheckIn`. |
| Cliente | `core:NoClip`, `target:Chair`/`UpChair`, `target:UpBed`/`StartTreatment`, `target:RollVehicle`, `service:Client`. |

## Customização

- **Mundo vivo:** tabela `NPCSystem` em `Global.lua`.
- **Academia:** `shared-side/academy.lua` (\+ pesos VIP em `server-side/target.lua`).
- **Centro médico/blackout:** valores em `server-side/target.lua`.
- **Macas/cadeiras/peds/blips/teleportes:** tabelas nos respectivos arquivos.
- **Interações:** `client-side/interactions.lua`.

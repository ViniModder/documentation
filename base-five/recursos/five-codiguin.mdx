O **five-codiguin** é o sistema de resgate de códigos promocionais do servidor. O jogador abre um painel (`/codiguin`), digita um código e, se válido e ainda não usado, recebe as recompensas. O código é **normalizado** (maiúsculas, sem espaços), e o resgate é **único por personagem** (gravado em `playerdata`).

## Funcionalidades

## Configuração

Todo o ajuste fica em `config/config.lua` (tabela `Codiguin`).

<AccordionGroup>
  <Accordion title="config/config.lua — Configuração e códigos" icon="sliders">
    ```lua
    Codiguin.Command = "codiguin"
    Codiguin.StorageKey = "five_codiguin_used"   -- chave em playerdata
    Codiguin.ThemeColor = "#e77a2a"              -- Theme.main tem prioridade
    
    Codiguin.Codes = {
        ["INAUGUROU"] = {                          -- a CHAVE é o código digitado
            label = "INAUGUROU",
            description = "🚘 Veículo 7 dias<br>💸 R$ 20.000<br>💎 60 Gemas",
            rewards = {
                money   = 20000,                   -- item dollar (se > 0)
                gems    = 60,                      -- gemas (se > 0)
                vehicle = { model = "ikx3gt3rs23", days = 7 },  -- aluguel (se model e days > 0)
                -- items = { { item = "id_item", amount = 1 } },  -- itens (opcional)
            },
        },
    }
    ```
  </Accordion>
</AccordionGroup>

## Comandos

| Comando | Descrição |
| --- | --- |
| `/codiguin` | Abre o painel de resgate (qualquer jogador). |

---

## Localizações

O recurso não possui locais fixos no mundo (sem NPCs, blips, marcadores ou zonas). O painel é aberto apenas pelo comando `/codiguin`.

---

## Exports

Não publica exports próprios. O Tunnel `five-codiguin` expõe `Core.Redeem(code)`.

---

## Banco de Dados

Não cria tabela própria, usa `playerdata` do vRP. Guarda um mapa `{ ["CODIGO"] = timestamp }` por personagem sob a chave `Codiguin.StorageKey`.

---

## Customização

- **Novos códigos:** adicione entradas em `Codiguin.Codes` (chave = código em MAIÚSCULAS sem espaços).
- **Recompensas combinadas:** misture `money`, `gems`, `vehicle` e `items` na mesma entrada.
- **Comando/tema:** `Codiguin.Command`, `Codiguin.ThemeColor`.

<Note>
  A UI é distribuída compilada em `web/dist/` (sem `src` no recurso).

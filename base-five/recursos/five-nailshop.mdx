O **five-nailshop** é um salão de manicure onde um jogador (manicure) abre o menu de design e cria unhas para outro (cliente) sentado numa cadeira do estúdio. Estúdios em `NailStudios` (com mesas `customer`/`employee`). Modo **público** (`job = false`: o próprio jogador senta e se atende) ou **convite** (`job = "..."`: o funcionário convida o cliente por ID). A interação é via `sleepless_interact`. Designs salvos são sincronizados por distância e persistidos.

## Configuração

<AccordionGroup>
  <Accordion title="config/main.lua — Configurações principais" icon="sliders">
    ```lua
    Debug = false,
    AutoRunSQL = true,        -- cria a tabela nailshop automaticamente
    Locale = 'pt',            -- locales/: en, pt, tr
    Target = 'auto',
    Notify = 'auto',
    
    NailStudios = {
        {
            name = "Harem",
            coords = vec3(217.09, -1544.95, 28.29),
            job = false,       -- false = público | "nome_job" = modo convite
            tables = {
                {
                    customer = { coords = vec4(...), cameraOffset = vec3(...), chairOffset = vec3(...) },
                    employee = { coords = vec4(...), chairOffset = vec3(...) },
                },
            },
        },
    },
    
    BlipSettings = { sprite = 279, color = 8, scale = 0.7, name = "Estudio de Unhas" },
    
    FingerBones = { ['left_hand_1'] = 45, ['right_hand_5'] = 89, ... },  -- dedo → bone do ped
    ```

    <Warning>
      **`Commands.reload_nails`** existe no config mas **não há comando registrado** nesta versão (sem efeito).
    </Warning>
  </Accordion>
</AccordionGroup>

## Customização

- **Estúdios/mesas:** `Config.NailStudios` (público com `job = false` ou convite com `job = "..."`).
- **Blip:** `Config.BlipSettings`.
- **Posicionamento das unhas:** `Config.FingerBones` (dedo→bone) \+ tabela `nailsPosition` em `client/cl_main.lua` (offset/rotação por comprimento).
- **Idioma:** `Config.Locale` \+ arquivos em `locales/`.
- **Assets:** modelos `.ydr`/`.ytd` em `stream/` (`qua_nail_<comprimento>_<estampa>`), declarados no `fxmanifest.lua`.

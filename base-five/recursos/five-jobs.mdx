O **five-jobs** é a central de empregos legais do servidor. O jogador interage com a **Agência de Empregos** (ponto físico no mapa via `sleepless_interact`), escolhe um emprego na interface NUI e cumpre rotas/coletas pela cidade para ganhar itens, dinheiro e XP.

## Configuração

<AccordionGroup>
  <Accordion title="config/config.lua — Agência de empregos" icon="building">
    ```lua
    Config.jobsAgencies = {
        coords = { {-268.97,-956.1,31.22,18.57} },  -- pontos da agência
        blip   = { show = true, id = 642, color = 50, size = 0.8, name = "Agência de Empregos" },
        command = { enabled = true, name = "empregos", permission = {"cadmin","admin","founder"} }
    }
    ```

    <Warning>
      a sub-tabela `command` está definida mas **não é usada**, não existe `RegisterCommand` para abrir a agência. Ela só abre pelo ponto de interação físico.
    </Warning>
  </Accordion>

  <Accordion title="config/config.lua — Cores e dica na tela" icon="palette">
    ```lua
    Config.markerColor = "#0143BB"  -- cor dos markers no mundo
    Config.ThemeColor  = "#0143BB"  -- cor da interface React
    Config.jobTipPosition = "bottom-left"  -- posição do balão de dica do emprego
    ```
  </Accordion>

  <Accordion title="config/config.lua — Níveis e XP" icon="chart-line">
    ```lua
    -- XP por nível DENTRO do emprego (lido diretamente do config):
    Config.perJobLevels = { [1]=500, [2]=1200, [3]=2500, ... [10]=35000 }
    -- Bônus de recompensa por nível do emprego:
    Config.perLevelMultiplier = { [1]=0.05, [2]=0.10, ... [10]=1.50 }
    ```

    <Warning>
      o nível **geral** do trabalhador NÃO usa `Config.workerLevels`. O servidor usa uma tabela local fixa em `server-side/core.lua`:

      ```lua
      local WorkerLevels = { [1] = 1000, [2] = 15000, [3] = 45000 }  -- só 3 níveis!
      ```

      Para alterar a curva do nível geral, edite essa tabela `WorkerLevels` no servidor (o `Config.workerLevels` sozinho não tem efeito).
    </Warning>

    **Cálculo do multiplicador:** a cada coleta, o bônus final é `multiplicador_do_emprego + multiplicador_geral`. A quantidade entregue é `base + floor(base * multiplicador)`.
  </Accordion>

  <Accordion title="config/config.lua — Bônus por horas trabalhadas" icon="clock">
    ```lua
    Config.bonusByWorkedHours = {
        enabled = true,
        resetEveryDays = 12,       -- reinicia o progresso a cada 12 dias
        rewards = {
            { workedHours = 1,  reward = 400   },
            { workedHours = 75, reward = 67000 },
        }
    }
    ```
  </Accordion>

  <Accordion title="config/config.lua — Missões" icon="list-check">
    ```lua
    Config.missions = {
        { id = 1, jobId = "motorista", title = "Pegar 25 passageiros",
          description = "...", target = 25, xp = 5000 },
    }
    ```

    `id` único, `jobId` válido (deve existir em `Config.professions`), `target` (nº de coletas), `xp` (XP geral).
  </Accordion>

  <Accordion title="config/professions.lua — Definição dos empregos" icon="briefcase">
    Cada chave é o `jobId`:

    ```lua
    ["minerador"] = {
        name = "Mineração",
        description = "...",
        image = "minerador.png",
        expGainPerCollect = 50,             -- XP por coleta
        clothes = { ["male"] = {...}, ["female"] = {...} },  -- uniforme por gênero
        collectItems = {                     -- itens SEMPRE recebidos
            { item = "silver", amount = {1,3} },  -- {min,max} ou número fixo
        },
        extraItems = { { item = "diamond", amount = {1,1} } },  -- itens RAROS
        extraItemsChance = 5,               -- chance (%) de cair um extraItem
        requiredItems = { { items = {"fishingrod"}, consume = 1, notify = "..." } },
    }
    ```

    - `collectItems`: `item = "dollar"` entrega dinheiro. Quantidade fixa ou `{min,max}`.
    - `requiredItems`: itens exigidos/consumidos; `consume` desconta do inventário.
    - `clothes`: `{drawable, texture}` por componente. A roupa original é restaurada ao sair.

    <Note>
      **`displaySalary` / salário:** nenhum emprego define `displaySalary`, então o salário aparece como **0** na NUI. Para exibir, adicione `displaySalary = <numero>` na definição (campo cosmético; a recompensa real vem de `collectItems`).

      **`requiredLevel`** existe em vários empregos mas o servidor **não bloqueia** o início por nível (hoje é só informativo).
    </Note>
  </Accordion>

  <Accordion title="config/routes.lua — Rotas e coordenadas" icon="map-pin">
    Define, por `jobId`, coordenadas e parâmetros (`requiredVehicle`, `routePoints`, `crops`, `trees`, etc.). Edite para mudar onde cada emprego acontece.
  </Accordion>
</AccordionGroup>

## Customização

### Adicionar um novo emprego

<Steps>
  <Step title="config/professions.lua">
    Adicione a definição (`name`, `expGainPerCollect`, `collectItems`, opcional `displaySalary`).
  </Step>
  <Step title="config/routes.lua">
    Adicione as coordenadas/rota.
  </Step>
  <Step title="client-side/professions.lua">
    Em `jobThread`, adicione um `elseif jobId == "meu_emprego" then` com a lógica (copie de um emprego parecido).
  </Step>
</Steps>

### Ajustar recompensas/níveis

- Recompensa real = `collectItems`/`extraItems` (config/professions.lua).
- Curva por emprego: `Config.perJobLevels` \+ `Config.perLevelMultiplier`.
- Curva geral: edite `WorkerLevels` no topo de `server-side/core.lua`.
- Bônus por horas e missões: `Config.bonusByWorkedHours` e `Config.missions`.

title: "five-routes"
description: "Sistema de rotas de farm: o jogador abre um ponto (NPC), escolhe insumos e um estilo (terrestre/aquática/aérea), paga o custo e percorre pontos no mapa guiado por GPS, coletando itens. Suporta multiplicadores por horário, por zona e bônus VIP."
---

O **five-routes** é um sistema de rotas de farm: cada ponto físico (`Routes.Points`) é vinculado a rotas (`Routes.Routes`) que definem insumos, custos e recompensas. Ao iniciar, o servidor valida permissão/itens/cobrança e escolhe uma pool de coordenadas conforme o estilo; o cliente cria blips de GPS em sequência (rota cíclica) e o jogador coleta em cada parada.

<Note>
  A **permissão é verificada pela chave do ponto** (ex.: para acessar `Municao1`, o jogador precisa da permissão vRP `Municao1`). O estado é só em memória (uma rota ativa por jogador, sem persistência).
</Note>

## Configuração

<AccordionGroup>
  <Accordion title="config/config.lua — tabela Routes" icon="sliders">
    ```lua
    Routes.Images = { BaseUrl = ItemsURL, Extension = ".png" }
    Routes.ThemeColor = "#0143bb"                  -- Theme.main tem prioridade
    Routes.NotificationPosition = "bottom-left"    -- posição do HUD de progresso
    
    Routes.Interaction = { System = "sleepless", AutoCloseDistance = 4.0, Sleepless = {...}, OxTarget = {...}, Marker = {...} }
    
    Routes.ZoneSettings = {
        terrestrial = { autoCollect = false, collectDistance = 3.0, markerDistance = 30.0, requiresOnFoot = true, collectAnim = {...} },
        aquatic     = { autoCollect = true,  collectDistance = 6.0, ... },
        aerial      = { autoCollect = true,  collectDistance = 15.0, markerType = 6, ... },
    }
    Routes.StyleToZone = { terrestre = "terrestrial", aquatica = "aquatic", aerea = "aerial" }
    Routes.DefaultCoordsZones = { terrestrial = "New", aquatic = "Aquaticas", aerial = "Aerea" }
    ```
  </Accordion>

  <Accordion title="Multiplicadores — FarmBuff e VipBonus" icon="chart-line">
    ```lua
    Routes.FarmBuff = {
        Enabled = true, Multiplier = 1,
        ZoneMultiplier = { terrestrial = 1.0, aquatic = 2.0, aerial = 1.0 },
        Schedule = { Segunda = { Enabled = true, StartHour = 6, EndHour = 16 }, ... },  -- buff por dia/hora
        Notify = { Enabled = false, Message = "..." },
    }
    Routes.VipBonus = { Enabled = true, Export = "seattle-bonuses", Function = "GetBonusFarm" }
    ```
  </Accordion>

  <Accordion title="Rotas e pontos — Routes.Routes e Routes.Points" icon="route">
    ```lua
    Routes.Routes = {
        Importacao = {
            RouteCost = 500,        -- custo base (0 = grátis)
            UpgradeStress = 1,      -- estresse por coleta
            CallPolice = false,     -- alerta a polícia?
            UsingVehicle = true,    -- permite coletar em veículo?
            Items = { { id = "aluminiofarm", price = 50, reward = { min = 2, max = 4 } } },  -- id = spawn do item
        },
    }
    
    Routes.Points = {
        Municao1 = {                              -- a CHAVE é a permissão exigida
            Routes = { "Municao" },               -- rotas disponíveis no ponto
            Coords = vec4(402.03,-4.98,84.92,238.12),
            NPC = true, Hash = "s_m_y_dealer_01", anim = { "dict", "anim" },
            -- AllowedStyles, CoordsZones, Blip são opcionais
        },
    }
    ```

    `Routes.Coords` define as pools (`New` terrestres, `Aquaticas`, `Aerea`).
  </Accordion>
</AccordionGroup>

## Customização

- **Novo ponto/NPC:** entrada em `Routes.Points` (chave = permissão vRP).
- **Nova rota/item:** entrada em `Routes.Routes` (`id` = spawn de item válido).
- **Interação:** `Routes.Interaction.System`.
- **Pontos de coleta:** edite `Routes.Coords` (pools).
- **Economia:** `RouteCost`, `price`, `reward {min,max}`, `UpgradeStress`; multiplicadores em `FarmBuff`/`VipBonus`.
- **Aparência:** `Routes.ThemeColor`, `Routes.NotificationPosition`.

description: "Desmanche de veículos: o jogador leva um veículo a um ponto, remove peças (portas, rodas, motor, escapamento) com animações, deposita na estante e recebe dinheiro sujo. Inclui painel NUI por organização, modo público com porcentagem, relocação do ponto e integração com garagem."
---

O **five-dismantle** cria pontos de desmanche (`Dismantle.Locations`). Fluxo: motorista pressiona `E` no marcador → lobby (todos no veículo entram) → progresso (ocupantes removem peças com barra de progresso) → cada peça é carregada até a estante e depositada → ao remover tudo (ou esgotar o tempo) o veículo é deletado e o pagamento é processado.

<Note>
  O líder não pode morrer nem se afastar mais de 50m. Veículos de NPC podem ser desmanchados se `AllowNpcVehicles = true`. Coordenadas alteradas pelo painel são persistidas e sobrescrevem a config.
</Note>

## Configuração

`config/config.lua` (tabela `Dismantle`):

<AccordionGroup>
  <Accordion title="config/config.lua — Configurações principais" icon="sliders">
    ```lua
    Dismantle.ThemeColor = "#0143bb"        -- Theme.main tem prioridade
    Dismantle.SessionVerifier = true        -- bloqueia se routing bucket ≠ 0
    Dismantle.AllowNpcVehicles = true       -- permite desmanchar carros de rua (NPC)
    Dismantle.Timers = { Lobby = 15, Progress = 300 }  -- segundos
    Dismantle.PanelCommand = "desmanche"
    
    Dismantle.PartsTimes = {                -- tempo (ms) por peça (padrão 10000)
        ["door_dside_f"] = 10000, ["wheel_lf"] = 7000, ["engine"] = 15000, ["exhaust"] = 7000, ...
    }
    
    Dismantle.PartItems = {                 -- item entregue por categoria
        ["money"] = "dollars", ["doors"] = "pizza", ["wheels"] = "pizza", ["ehxausts"] = "pizza", ["batteries"] = "pizza",
    }
    
    Dismantle.DefaultVehiclePrice = 50000
    Dismantle.DefaultPaymentPercent = 0.90  -- % paga ao jogador (carros fora das classes custom)
    
    Dismantle.VehiclePrices = {             -- valor base por classe nativa do GTA (chave = id string)
        ["0"] = 10000, ["7"] = 120000, ["8"] = 20000, ["19"] = 80000, ...
    }
    
    Dismantle.CustomClasses = {             -- valor + percent por modelo (prioridade sobre VehiclePrices)
        ["luxo"] = { price = 200000, percent = 0.0, models = { "adder", "zentorno", "t20" } },
    }
    
    Dismantle.Interaction = { DrawDistance = 25.0, InteractDistance = 10.0, StartDistance = 1.2, Key = 38 }
    Dismantle.BlockedAreas = { { center = vec3(-1268.62,-1482.11,4.31), radius = 60 } }
    ```
  </Accordion>

  <Accordion title="Pontos (Locations)" icon="map-pin">
    ```lua
    Dismantle.Locations = {
        ["desmanche-1"] = {
            name = "Yellow Jack", cooldown = 60, hasPanel = true,
            permissions = { use = "Desmanche1", manage = "Desmanche1" },
            coords = { vehicle = { 1984.42,3033.06,47.11,235.28 }, shelf = { 1989.59,3035.36,47.11,334.49 } },
            allowedClasses = { ["0"]=true, ["7"]=true, ["18"]=false, ["19"]=false, ... },
            allowedRelocationArea = { center = vec3(1984.42,3033.06,47.11), radius = 250.0 },
        },
        -- desmanche-2, desmanche-3, desmanche-4
    }
    ```
  </Accordion>

  <Accordion title="Hooks (funções editáveis)" icon="code">
    ```lua
    Dismantle.CanVehicleBeDismantled = function(entity, plate, model, class) return true end  -- regra de bloqueio
    Dismantle.OnPayment = function(source, userId, data, overTime) ... end  -- lógica de pagamento (player/painel, garagem, logs)
    ```

    Webhooks em `config/webhooks.lua`: `DismantleCompleted`, `PanelAction`.
  </Accordion>
</AccordionGroup>

## Banco de Dados

`five_dismantle` criada automaticamente. Por ponto com painel, guarda coordenadas customizadas e itens acumulados (`money`, `wheels`, `doors`, `ehxausts`, `batteries`, `public`, `percent`).

---

## Customização

- **Regras/pagamento:** hooks `CanVehicleBeDismantled` e `OnPayment`.
- **Preços:** `CustomClasses`, `VehiclePrices`, `DefaultVehiclePrice`/`DefaultPaymentPercent`.
- **Itens por peça:** `PartItems`. **Tempo por peça:** `PartsTimes`.
- **Pontos:** `Dismantle.Locations` (`allowedClasses`, `permissions`, `allowedRelocationArea`).
- **Webhooks:** `config/webhooks.lua`.

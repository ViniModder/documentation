---
title: "five-crafting"
description: "Sistema de fabricação (crafting) com interface NUI em React. Cria estações de craft no mapa, com receitas por categorias, restrições por grupo/rank do vRP, consumo de ingredientes, barra de progresso e log via webhook."
---

O **five-crafting** adiciona pontos de fabricação ("estações") pelo mapa. Cada estação é aberta por um sistema de interação configurável (`sleepless_interact`, `ox_target` ou marcador 3D), pode exigir um grupo/rank do vRP (ou ser pública) e disponibiliza uma ou mais **categorias de receitas**.

Ao fabricar, o servidor valida permissão, limite de itens, peso e ingredientes; consome os ingredientes; dispara a barra de progresso; entrega o item e registra no webhook/`five_logs`. Toda manipulação de itens é via **vRP**, e o recurso **não acessa o banco diretamente**.

## Configuração

Tudo em `config/config.lua` (webhooks em `config/webhooks.lua`).

<AccordionGroup>
  <Accordion title="Imagens e tema" icon="image">
    ```lua
    Crafting.Images = {
        BaseUrl   = ItemsURL,   -- vem de vrp/config/Global.lua (cdn.fivenetwork.dev/Itens/)
        Extension = ".png",
    }
    Crafting.ThemeColor = "#0143bb"  -- Theme.main tem prioridade
    ```
  </Accordion>

  <Accordion title="Interação" icon="hand-pointer">
    ```lua
    Crafting.Interaction = {
        System = "sleepless",      -- "sleepless" | "ox_target" | "marker"
        AutoCloseDistance = 4.0,   -- distância para fechar o painel automaticamente
        Sleepless = { Label = "Abrir Fabricação", Icon = "wrench", Distance = 2.0, ... },
        OxTarget  = { Label = "Abrir Fabricação", Icon = "fa-solid fa-wrench", Radius = 1.0, ... },
        Marker    = { Key = 38, Text = "~g~E~w~  ABRIR FABRICAÇÃO", Color = {1,67,187,160}, ... },
    }
    ```
  </Accordion>

  <Accordion title="Estações" icon="map-pin">
    ```lua
    Crafting.Stations = {
        -- Estação com grupo + rank:
        { Coords = vec3(412.64,8.11,84.74), Permission = "Municao1", Rank = 3, Modes = { "Municao" } },
        -- Estação PÚBLICA (sem Permission/Rank):
        { Coords = vec3(-248.67,-2208.34,9.89), Modes = { "LavagemPublica" } },
    }
    ```

    | Campo | Descrição |
    | --- | --- |
    | `Coords` | Coordenada do ponto. **Obrigatório.** |
    | `Permission` | Grupo vRP necessário. `nil` = pública. |
    | `Rank` | Nível mínimo no grupo. `nil` = qualquer. |
    | `Modes` | Lista de categorias de receitas (chaves de `Crafting.Recipes`). **Obrigatório.** |

    <Note>
      Uma estação pode listar várias categorias em `Modes` (a UI mostra a união).
    </Note>
  </Accordion>

  <Accordion title="Receitas" icon="list">
    `Crafting.Recipes` é uma tabela de **categorias**, cada uma com uma `List`. A **chave de cada receita é o spawn do item produzido**:

    ```lua
    Crafting.Recipes = {
        Municao = {
            List = {
                caixapistolammo = {
                    Amount = 1,                              -- quantidade produzida
                    Time = 1,                                -- tempo de fabricação (segundos)
                    Required = { polvorafarm = 50, capsula = 50 }  -- ingredientes
                },
            }
        },
    }
    ```

    Categorias de fábrica: `Armas`, `Parafal`, `Municao`, `Lavagem`, `Ilegal`, `Desmanche`, drogas (`LSD`, `Cocaina`, `Skunk`, etc.), `SodaPOP`, `Marina`, entre outras.

    <Warning>
      O servidor só inclui receitas cujo item de saída exista no `Item.lua` (`ItemExist`). **Cadastre o item no `Item.lua` do vRP antes de usá-lo numa receita.** A ordem das chaves no arquivo define a ordem na UI.
    </Warning>
  </Accordion>

  <Accordion title="Webhooks" icon="discord">
    ```lua
    -- config/webhooks.lua
    local webhookURLs = { fabricacao = "" }  -- URL do Discord; vazio = sem log
    ```
  </Accordion>
</AccordionGroup>

## Exports

O recurso **não expõe exports próprios** (apenas consome `sleepless_interact`, `ox_target`, `five_logs`).

---

## Eventos

Eventos de integração no cliente para abrir e fechar o painel de uma estação.

| Evento | Parâmetros | Descrição |
| --- | --- | --- |
| `five-crafting:open` | `stationIndex` (number) | Abre o painel da estação cujo índice em `Crafting.Stations` é `stationIndex`. |
| `five-crafting:close` | N/A | Fecha o painel. |

```lua
TriggerEvent("five-crafting:open", 1)  -- abre a 1ª estação da config
```

<Note>
  O `stationIndex` é a posição numérica em `Crafting.Stations`. A permissão é revalidada no servidor.
</Note>

---

## Banco de Dados

**Nenhuma tabela.** Todo o estado (itens, peso, grupos) é gerenciado pelo vRP (`vRP.ItemAmount`, `vRP.TakeItem`, `vRP.GenerateItem`, `vRP.HasGroup`, etc.). Os itens das receitas precisam existir no `Item.lua`.

## Customização

### Adicionar uma nova receita

<Steps>
  <Step title="Garanta os itens no Item.lua">
    Garanta que o item produzido e os ingredientes existem no `Item.lua` do vRP.
  </Step>
  <Step title="Adicione a receita na categoria">
    Em `Crafting.Recipes`, escolha a categoria e adicione em `List` (chave = spawn do produto):

    ```lua
    caixarifleammo = {
        Amount = 1,
        Time   = 5,
        Required = { polvorafarm = 150, capsulafuzil = 150 }
    }
    ```
  </Step>
</Steps>

### Adicionar categoria \+ estação

<Steps>
  <Step title="Crie a categoria">
    Crie a categoria em `Crafting.Recipes` (com sua `List`).
  </Step>
  <Step title="Crie a estação">
    Crie a estação em `Crafting.Stations` apontando em `Modes`:

    ```lua
    { Coords = vec3(100.0,200.0,30.0), Permission = "MeuGrupo", Rank = 1, Modes = { "MinhaCategoria" } }
    ```
  </Step>
</Steps>

<Tip>
  - **Limite por craft:** UI limita 1–999 (`web-side/src/store/useCraftingStore.ts`); servidor força mínimo 1 e multiplica `Amount`/`Time`/`Required`.
  - **Notificações:** tipos/cores em `config/functions.lua` (`NotifyTypes`).
  - **Logs:** com `five_logs` ativo, cada craft gera log `"CRAFTOU"`.
</Tip>

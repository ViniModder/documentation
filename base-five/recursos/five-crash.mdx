O **five-crash** cria eventos de "crash" no mapa: um veículo cai e gera baús de loot ao redor, disputados em uma área de PvP. Pode ser iniciado por comando admin ou automaticamente por horário (`Crash.Schedule`). O servidor monta o loot (de `Crash.LootTables`), marca os baús como "quentes" no recurso `chest` e propaga via `GlobalState`. Mortes dentro da área alimentam um killfeed. O evento termina quando os baús esvaziam (`GlobalState.Helibox <= 0`) ou o tempo expira.

## Configuração

`config/config.lua` (tabela `Crash`):

<AccordionGroup>
  <Accordion title="config/config.lua — Configurações principais" icon="sliders">
    ```lua
    Crash.ThemeColor = "#0143bb"
    Crash.Permission = "Admin"          -- comandos (aceita "Grupo@Nivel")
    Crash.Commands = { Start = "crash", Random = "crashstart", Stop = "crashstop", Special = "specialcrash", ... }
    
    Crash.Times = { Duration = 1200, SpawnCooldown = 420 }  -- evento (s) / cooldown (s)
    Crash.MinPlayers = 10               -- mínimo online p/ auto-spawn
    Crash.AreaSize = 280                -- raio da área de combate
    Crash.SpawnDistance = 400           -- distância p/ criar os props
    Crash.ChestPrefix = "Helicrash"     -- container Prefix:N (contrato com o chest)
    
    Crash.Respawn = { Enable = true, Timer = 5, Item = "adrenaline", Health = 200, Coords = {...} }
    
    Crash.SpecialTime = "21:00"         -- dispara o crash especial
    Crash.Schedule = { ["00:00"] = true, ... ["23:00"] = true }  -- horários de auto-spawn (heli aleatório)
    
    Crash.Logs = { Started = "", Finished = "", CombatLog = "" }  -- webhooks
    Crash.Names = { heli = "Helicóptero", truck = "Caminhão", stock = "Carro Forte", stockade = "..." }
    Crash.Messages = { heli = "Mayday!...", ... }  -- anúncios por tipo
    Crash.Props = { heli = { Vehicle = "snt_crash_helicopter", Chest = "prop_mil_crate_01" }, ... }
    
    Crash.Special = { Type = "stockade", LootMultiplier = 2, Bonus = { item = "gemstone", amount = 10 }, Vehicle = {...}, Chests = {...} }
    
    Crash.Locations = {  -- locais [1]-[11]
        [1] = { Vehicle = { x=..., y=..., z=..., h=... }, Chests = { {x,y,z,h}, ... } },
    }
    
    Crash.LootTables = {  -- sorteia UMA por baú; no especial multiplica por LootMultiplier
        { { item = "dirtydollar", amount = 10000 }, { item = "c4", amount = 8 }, ... },
    }
    ```
  </Accordion>
</AccordionGroup>

## Comandos

Comandos administrativos para iniciar e finalizar eventos de crash.

| Comando | Uso | Função |
| --- | --- | --- |
| `/crash <tipo> [local]` | heli/truck/stock/stockade; local 1-11 | Inicia um crash. |
| `/crashstart` | N/A | Crash de heli em local aleatório. |
| `/specialcrash` | N/A | Crash especial (`Crash.Special`). |
| `/crashstop`, `/endcrash` | N/A | Finaliza o evento. |

## Exports

Exports para consultar o estado do evento ativo.

```lua
exports["five-crash"]:IsActive()       -- há crash ativo?
exports["five-crash"]:GetTimer()       -- tempo restante "MM:SS"
exports["five-crash"]:InCrash(Coords)  -- coords dentro da área?
```

## Customização

- **Locais/baús:** `Crash.Locations` (limpeza interna percorre até 6 baús).
- **Loot:** `Crash.LootTables`, e `LootMultiplier`/`Bonus` no especial.
- **Tipos/props:** `Crash.Props`, `Crash.Names`, `Crash.Messages`.
- **Agenda/ritmo:** `Crash.Schedule`, `SpecialTime`, `Times`, `MinPlayers`.
- **Área:** `AreaSize`, `SpawnDistance`. **Respawn:** `Crash.Respawn`.
- **Logs:** `Crash.Logs`.

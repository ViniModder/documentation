O **five-elevator** cria pontos de interação em coordenadas pré-definidas. Cada "elevador" é um conjunto de andares (`floors`), cada um com coordenadas próprias. Ao interagir, o jogador vê a lista de andares (o andar atual é calculado por proximidade e fica desabilitado) e seleciona o destino. A lista é filtrada por permissão no servidor; o andar de origem nunca é ocultado.

## Configuração

`config/config.lua` (tabela `Elevator`):

<AccordionGroup>
  <Accordion title="config/config.lua — Tema, interação e elevadores" icon="sliders">
    ```lua
    Elevator.ThemeColor = "#0143bb"   -- Theme.main tem prioridade
    
    Elevator.Interaction = {
        System = "sleepless",          -- só "sleepless" está implementado
        Sleepless = { Label = "Abrir Elevador", Icon = "elevator", Distance = 1.5 },
    }
    
    Elevator.Locations = {
        -- cada item é um elevador; o ÍNDICE (1,2,3...) é o id interno
        {
            -- permission = "Grupo",  -- (opcional) permissão para o elevador inteiro
            floors = {
                { label = "Heliponto", coords = { -1023.66, -432.89, 77.36, 116.23 } },
                { label = "Térreo",    coords = { -1025.2, -429.37, 39.82, 150.24 } },
                { label = "Escritório", coords = { -673.81,-688.87,30.31,181.42 }, permission = "Lavagem3" },
            },
        },
    }
    ```

    Cada andar (`floor`): `label`, `coords` (`{x,y,z[,heading]}`; teleporta em `z-1`) e `permission` opcional (string → `HasPermission`, ou tabela → `HasTable`). Andares com `permission` só aparecem para quem tem acesso (exceto o andar de origem).

    <Note>
      Já vêm 14 elevadores configurados (Hospital, Torre, DP Civil, etc.).
    </Note>
  </Accordion>
</AccordionGroup>

## Customização

- **Novo elevador:** adicione uma entrada em `Elevator.Locations` com sua lista `floors`.
- **Andares:** edite `floors` (lembre que `z-1` é o destino).
- **Restrição por andar/elevador:** campo `permission` (string ou tabela).
- **Ponto de interação:** `Elevator.Interaction.Sleepless`.
- **Cor:** `Elevator.ThemeColor` (ou `Theme.main`).

---

O **five-creator** controla todo o fluxo visual do personagem desde o primeiro login. O fluxo é automático: ao entrar, após 10s o cliente chama `five-creator:Server:Spawn`. Se já há personagens na licença, abre o **Selector**; senão, abre o **Creator**. A UI é React/Vite compilada em `web-side/dist/`.

## Funcionalidades

## Configuração

<AccordionGroup>
  <Accordion title="Config.lua — tema e câmeras" icon="palette">
    ```lua
    Config.AssetsUrl = "https://cdn.fivenetwork.dev/CorePerson/"  -- URL base das imagens
    Config.Logo = "https://cdn.fivenetwork.dev/CorePerson/logo.png"
    Config.ThemeColor = "#0143bb"
    Config.Color = { 1, 67, 187 }  -- RGB dos marcadores 3D
    ```

    `Config.Cameras` define posições de câmera por foco (`fullbody`, `face`, `torso`, `eyes`, `hair`, etc.), cada uma com `distance`, `height` e `pointOffSet`.
  </Accordion>

  <Accordion title="config/Creator.lua" icon="user-pen">
    ```lua
    Config.Creator = {
        Coords = { x=-793.42, y=326.06, z=210.79, h=357.17 },  -- onde o ped fica na criação
        Spawn  = { x=-1038.18, y=-2738.68, z=13.82, h=330.54}, -- spawn do recém-criado
        Cutscene = true,  -- cutscene de introdução (mp_intro_concat) ao finalizar
    }
    ```

    Também define `Default.Appearance` (traços faciais iniciais; `-1` = nenhum), `Default.Clothes` (roupa inicial por gênero `m`/`f`), listas `Fathers`/`Mothers` (genética), e os sliders `Characteristics`, `Appearance` e `Hair` (cada um com `title`, `min`, `max`, `step`, `camera`).

    <Note>
      Validação na criação: idade entre **18 e 60**, nome e sobrenome com **≥ 4 caracteres**.
    </Note>
  </Accordion>

  <Accordion title="config/Selector.lua" icon="users">
    ```lua
    Config.Selector = {
        Main = vec3(-777.54,331.47,211.4),  -- onde o ped fica na seleção
        Command = { Name = "spawn" },        -- comando que reabre o seletor
        Vip = {
            Groups = { "Diamante","Ouro","Prata","Bronze","Streamer","Booster" },
            Time = 30  -- duração do VIP em dias
        },
    }
    ```

    Define também `Spawns` (5 poses de exibição dos personagens) e `Cameras` (5 sequências cinemáticas).

    <Note>
      A quantidade de slots vem de `vRP.Account(...)["Characters"]` (não deste config). `Config.Selector.Price` (preço de slot) não está definido por padrão, defina se quiser exibir um valor.
    </Note>
  </Accordion>

  <Accordion title="config/Spawn.lua" icon="map-pin">
    ```lua
    Config.Spawn = {
        Locations = {
            { id = "pracamaldivas", name = "PRAÇA", coords = vec3(185.02,-913.7,29.45) },
            { id = "hospitalmaldivas", name = "HOSPITAL SUL", coords = vec3(-1012.74,-440.61,39.61) },
        },
        CamHeights = { [1]=1500, [2]=1000, [3]=750, [4]=400, [5]=100 }  -- descida da câmera
    }
    ```

    Cada local: `id` (também a imagem `spawn/<id>.png`), `name`, `coords`.
  </Accordion>

  <Accordion title="Lojas (Barbershop, Skinshop, Tattooshop)" icon="store">
    Cada loja tem `MarkerTitle`, um bloco `Command` (`Name` \+ `Permissions`), um `Map` (itens/peças com preços) e `Locations` (pontos com `radius` e `viewRadius`).

    - **Barbershop**: `Map` em `hair` e `makeup`; todos os itens custam **250**. 8 localizações.
    - **Skinshop**: `Map` por peça (`mask`=500, `watch`=700, `arms`=300, etc.). 18 localizações.
    - **Tattooshop**: `Map[gênero][parteDoCorpo]` com `Price` (250), `Camera` e `List` de overlays. 8 localizações.

    O preço é cobrado por item **alterado** em relação ao atual. Dentro do criador, o preço é `0`.
  </Accordion>
</AccordionGroup>

## Comandos

Comandos administrativos para reabrir o seletor e as lojas, e para resetar personagens.

| Comando | Permissão | Função |
| --- | --- | --- |
| `/spawn [id]` | Admin/Mod | Logout do personagem e reabre o Selector. Admin/Mod podem forçar outro jogador. |
| `/barbershop` | Admin hier. 4 | Abre a barbearia para si. |
| `/skinshop` | Admin hier. 4 | Abre a loja de roupas para si. |
| `/tattooshop` | Admin hier. 4 | Abre o estúdio de tatuagem para si. |
| `/resetchar [id]` | Admin hier. 1 | Envia outro jogador de volta ao Creator (com confirmação). |

<Note>
  `Config.Resetchar` não vem definido por padrão, então `/resetchar` usa o nome e a permissão de fallback (`Admin` hier. 1). Defina `Config.Resetchar = { Command = ..., Permissions = {...} }` para customizar.
</Note>

## Exports

Funções via **Tunnel** (interface `five-creator`, tabela `vFunc`):

| Função | Retorno | Descrição |
| --- | --- | --- |
| `getCustomization()` | tabela | Roupa atual do personagem. |
| `checkBackpack()` | boolean | `true` se está usando mochila. |

Eventos de integração públicos: `barbershop:Open`, `skinshop:Open`, `tattooshop:Open`, `barbershop:Apply`, `skinshop:Apply`, `tattooshop:Apply`, `skinshop:setHat`/`setMask`/`setGlasses`, etc.

## Banco de Dados

O recurso utiliza duas tabelas para armazenar personagens e seus dados serializados.

| Tabela | Descrição |
| --- | --- |
| `characters` | Personagens por licença (`id`, `License`, `Name`, `Lastname`, `Sex`, `Blood`, `Phone`, `Skin`, `Bank`, `Deleted`, `vipDate`). Telefone único `DDD-DDDD`. |
| `playerdata` | Dados serializados (JSON) por categoria: `Barbershop` (aparência), `Clothings` (roupas), `Tattooshop` (tatuagens), `Datatable` (posição/vida ao deslogar). |

## Customização

### Trocar imagens (CDN)

Todas as imagens vêm de `Config.AssetsUrl`. Caminhos montados automaticamente:

- Pais: `creator/fathers/<name>.png` | Mães: `creator/mothers/<name>.png`
- Roupas: `skinshop/<section>/<genero>/<index>.webp`
- Cabelos: `barbershop/<genero>/<index>.webp`
- Tatuagens: `tattooshop/<genero>/<overlay>.webp`
- Spawn: `spawn/<id>.png`

Hospede suas imagens nessa estrutura e altere `Config.AssetsUrl`.

### Outros ajustes

- **Tema:** `Config.ThemeColor` / `Config.Color` (sobrescritos por `Theme.main` se existir).
- **Locais:** adicione/remova em `Locations` (lojas) e `Config.Spawn.Locations`.
- **Preços:** campo `price`/`Price` de cada item (0 = grátis). Cobra primeiro da carteira (`dollars`), depois do banco.
- **Cutscene:** `Config.Creator.Cutscene = false` pula a introdução.

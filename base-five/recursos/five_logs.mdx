O **core\_logs** é um recurso **standalone e exclusivamente server-side** (sem NUI, sem client). Centraliza o registro de ações importantes do servidor (entradas/saídas, ações admin, banco, inventário, prisões, roubos, empregos, etc.) e encaminha para um painel web externo. A integração com os outros recursos é por **um único ponto**: o export `AddLog`.

## Funcionalidades

</Note>

## Exports

### `AddLog(category, data)`

Registra um evento. **Fire-and-forget** (não bloqueia, não precisa de pcall). Só existe no server.

```lua
exports["five_logs"]:AddLog(category, data)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `category` | string | Tipo do evento. Convenção: MAIÚSCULAS, sem espaços/acentos (ex.: `BAN`, `PRISAO`, `ENTROU`). |
| `data` | table | Dados do log. 5 chaves têm tratamento especial (viram filtros no painel). |

**Chaves especiais de `data`:** `message` (frase principal, já montada com nomes/IDs reais), `adminName`, `adminId` (number), `playerName`, `playerId` (number). Qualquer outra chave é exibida como "dado extra".

Exemplo real:

```lua
exports["five_logs"]:AddLog("PRISAO", {
    message = vRP.FullName(Officer).." #"..Officer.." prendeu "..vRP.FullName(Passport).." #"..Passport,
    playerName = vRP.FullName(Passport),
    playerId = parseInt(Passport),
    Policial = vRP.FullName(Officer),
    Pena = Services.." minutos",
})
```

Padrão de wrapper local usado em vários recursos:

```lua
local function CoreLog(category, data)
    if GetResourceState("five_logs") == "started" then
        exports["five_logs"]:AddLog(category, data)
    end
end
```

<Note>
  É o único export do recurso.
</Note>

## Customização

- **Token:** `CoreLogs.Token` em `config/config.lua`.
- **O que é logado:** definido nos recursos que chamam `AddLog`, escolha `category` (reaproveite as existentes para consistência: `ENTROU`, `SAIU`, `SALARIO`, `MORTE`, `PRISAO`, `MULTA`, `BAN`, `KICK`, `CRAFTOU`, `ROUBO-ATM`, `DESMANCHE`, `TUNING-*`, `EMPREGO-*`, etc.), monte a `message` completa e preencha `adminId`/`playerId` (geram os filtros do painel).

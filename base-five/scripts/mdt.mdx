O **mdt** é o software interno dos grupos policiais. A interface abre quando o servidor recebe `mdt:Open` com o nome do grupo (disparado pelo menu "Computador" do recurso `dynamic`, que mapeia `Militar`, `Civil`, `CORE`, `BOPE`, `PRF`). O servidor valida `vRP.HasPermission(Passport, Group)` e guarda o grupo ativo em `Permission[Passport]`.

Toda comunicação NUI↔Lua usa Tunnel: o cliente expõe a interface `mdt` e cada `RegisterNUICallback` repassa para a função `Core.*` homônima no servidor. As descrições enviadas passam por sanitização (`<script>`, `on*=`). Com `five_logs` ativo, gera logs para prisão, multa, advertência, contratação, promoção/rebaixamento e demissão.

## Comandos

Nenhum. A interface é aberta pela interação do recurso `dynamic` (`mdt:Open`).

## Exports

Não declara exports próprios; consome `five-vehicles` (`updateVehicleStatus`), `vrp` (`Avatar`), `screenshot-basic`, `five_logs`.

---

## Eventos

### Interfaces Tunnel

Cliente e servidor expõem a interface `mdt` (`Tunnel.bindInterface("mdt", Core)`). Cada NUI callback repassa para a função `Core.*` homônima no servidor.

### Recebidos no servidor

| Evento | Descrição |
| --- | --- |
| `mdt:Open` | Abre o MDT para o grupo informado; valida `vRP.HasPermission` e guarda o grupo em `Permission[Passport]`. |
| `mdt:Vehicle` | Consulta a placa de um veículo (requer serviço `Policia`); responde via `mdt:Vehicle` no cliente. |

### Cliente

| Evento | Descrição |
| --- | --- |
| `mdt:Opened` | Abre a NUI e libera o foco/cursor. |
| `mdt:Vehicle` | Recebe os dados da consulta de placa e os envia à NUI. |
| `mdt:Refresh` | Dispara uma ação de atualização (`Action`) na NUI. |
| `mdt:UpdateUser` | Atualiza os dados do cidadão exibido na NUI. |
| `mdt:Notify` | Notificação interna (Título, Mensagem, Tipo). |

### NUI Callbacks

Cada callback chama a função `Core.*` correspondente no servidor via Tunnel.

| Grupo | Callbacks |
| --- | --- |
| Sistema | `Close`, `Config`, `Home`, `UpdateBoard` |
| Código penal | `PenalCode`, `CreatePenalCode`, `UpdatePenalCode`, `DestroyPenalCode`, `OrderPenalCode` |
| Cidadão | `Player`, `SearchUser`, `User`, `Avatar`, `Firearms`, `Flyingarms`, `Record`, `ClearRecord`, `ClearRecords` |
| Efetivo | `SearchOfficer`, `Officers`, `CreateOfficer`, `HierarchyOfficer`, `DismissOfficer` |
| Patrulhas | `Patrol`, `GetPatrol`, `CreatePatrol`, `UpdatePatrol`, `DestroyPatrol` |
| Operações | `Operations`, `GetOperation`, `CreateOperation`, `UpdateOperation`, `DestroyOperation`, `EscalatedOperation` |
| Penalidades | `ArrestRecords`, `Arrest`, `Fine`, `Warning` |
| Relatórios | `PoliceReports`, `GetPoliceReport`, `CreatePoliceReport`, `UpdatePoliceReport`, `ArchivePoliceReport` |
| Mandados | `Wanted`, `GetWanted`, `CreateWanted`, `UpdateWanted`, `DestroyWanted` |
| Corregedoria | `InternalAffairs`, `GetInternalAffairs`, `CreateInternalAffairs`, `UpdateInternalAffairs`, `ArchiveInternalAffairs` |
| Veículos apreendidos | `SeizedVehicles`, `CreateSeizedVehicle` |
| Medalhas | `Medals`, `GetMedal`, `CreateMedal`, `UpdateMedal`, `AssignMedal`, `RemoveMedal`, `DestroyMedal` |
| Unidades | `Units`, `GetUnit`, `CreateUnit`, `UpdateUnit`, `AssignUnit`, `RemoveUnit`, `DestroyUnit` |
| Banco do grupo | `Bank`, `DepositBank`, `WithdrawBank`, `TransferBank` |

## Banco de Dados

Tabelas próprias `mdt_creative_*`: `penalcode_sections`, `penalcode_articles`, `arrest`, `fines`, `warning`, `wanted`, `reports`, `internalaffairs`, `vehicles`, `medals`, `units`, `board`. Compartilhadas: `avatars` (foto do cidadão), `painel_creative_transactions` (extrato do banco do grupo).

<Note>
  Patrulhas e Operações são mantidas **apenas em memória** (não persistem em banco).
</Note>

---

## Customização

- **Permissões por funcionalidade:** `Config.Permissions` / `Config.OtherPermissions[grupo]` (regra `-1`/`0`/`N`).
- **Limites e taxas:** `MaxFine`, `MaxArrest`, reduções e taxas bancárias.
- **Locais de operação:** `Config.OperationsLocations`.
- **Grupos com acesso:** definidos no mapeamento do recurso `dynamic`.
- **Webhook de imagens:** convar `Discord_MDT`.

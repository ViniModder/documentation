O **ems** é um painel NUI ligado ao vRP para a gestão do corpo paramédico. O servidor expõe a interface `ems` (Tunnel) e o cliente consome via `vSERVER`. O painel é aberto pelo recurso `dynamic` (computador do hospital), que dispara `ems:Open` com o grupo (`HospitalNorte`/`HospitalSul`). Cada registro é gravado com a coluna `Permission = Group`, isolando os dados por hospital.

<Warning>**Não há sistema de morte/revive aqui**: este recurso é o painel de gestão. Morte/revive é tratado em outros recursos (ex.: `survival`/`paramedic`).</Warning>

## Configuração

<AccordionGroup>
  <Accordion title="shared-side/shared.lua — tabela Config" icon="sliders">
    ```lua
    Config = {
        BankTaxWithdraw = 1.0,      -- multiplicador no saque (1.0 = sem taxa)
        BankTaxTransfer = 1.0,      -- multiplicador na transferência
        MedicPlanDuration = 604800, -- duração do plano médico (s) = 7 dias
        MaxSpecialties = 20,
    }
    ```
  </Accordion>
  <Accordion title="Permissões por cargo" icon="user-shield">
    Nível 1 (líder) e grupo `Admin` têm acesso total. Demais níveis seguem o que está salvo em `EMS:Permissions:<Group>` (categorias: `Management`, `Announcements`, `Specialties`, `Bank`, `Paramedic`, `Consultations`, `Exams`, `MedicPlan`).
  </Accordion>

## Comandos

Nenhum. O painel abre via evento `ems:Open` (recurso `dynamic`).

---

## Eventos

`Tunnel.bindInterface("ems", Core)` no servidor e no cliente. O cliente consome o servidor via `vSERVER`; cada callback de NUI repassa a chamada para a interface `Core`.

### Recebidos no servidor

| Evento | Descrição |
| --- | --- |
| `ems:Open(Group)` | Valida permissão do jogador no grupo e abre o painel no cliente. |

### Cliente

| Evento | Descrição |
| --- | --- |
| `ems:Open` | Abre a NUI do painel do hospital. |
| `ems:Notify(Title, Message, Type)` | Exibe notificação na NUI. |

### NUI Callbacks

| Evento | Descrição |
| --- | --- |
| `Close` | Fecha o painel e libera o foco. |
| `Home` | Carrega a tela inicial. |
| `Consultations` | Lista as consultas do hospital. |
| `GetConsultation` | Retorna os dados de uma consulta. |
| `CreateConsultation` | Cria uma consulta. |
| `UpdateConsultation` | Atualiza uma consulta. |
| `DestroyConsultation` | Remove uma consulta. |
| `Exams` | Lista os exames do hospital. |
| `GetExam` | Retorna os dados de um exame. |
| `CreateExam` | Cria um exame. |
| `UpdateExam` | Atualiza um exame. |
| `DestroyExam` | Remove um exame. |
| `User` | Retorna dados do paciente pesquisado. |
| `UserConsultations` | Consultas do paciente. |
| `UserExams` | Exames do paciente. |
| `Avatar` | Captura/atualiza a foto do avatar (screenshot). |
| `MedicPlan` | Gerencia o plano médico do paciente. |
| `SearchUser` | Pesquisa jogador por passaporte/nome. |
| `Members` | Lista os membros do grupo. |
| `Specialties` | Lista as especialidades. |
| `GetSpecialty` | Retorna uma especialidade. |
| `CreateSpecialty` | Cria uma especialidade. |
| `UpdateSpecialty` | Atualiza uma especialidade. |
| `AssignSpecialty` | Atribui especialidade a um membro. |
| `RemoveSpecialty` | Remove especialidade de um membro. |
| `DestroySpecialty` | Exclui uma especialidade. |
| `Invite` | Convida um jogador para o grupo. |
| `Hierarchy` | Altera o cargo/nível de um membro. |
| `Dismiss` | Demite um membro. |
| `Announcements` | Lista os avisos. |
| `CreateAnnouncement` | Cria um aviso. |
| `UpdateAnnouncement` | Atualiza um aviso. |
| `DestroyAnnouncement` | Remove um aviso. |
| `Bank` | Retorna o caixa do grupo e o histórico. |
| `DepositBank` | Deposita no caixa do grupo. |
| `WithdrawBank` | Saca do caixa do grupo (aplica `BankTaxWithdraw`). |

| `Permissions` | Carrega as permissões por cargo. |
| `SavePermissions` | Salva as permissões por cargo. |

## Banco de Dados

Todas as tabelas são isoladas por `Permission`.

| Tabela / origem | Uso |
| --- | --- |
| `ems_creative_consultations` | Consultas do hospital. |
| `ems_creative_exams` | Exames do hospital. |
| `ems_creative_specialties` | Especialidades do hospital. |
| `avatars` | Fotos de avatar dos pacientes. |
| `painel_creative_announcements` | Avisos do hospital. |
| `painel_creative_transactions` | Histórico do banco do grupo. |
| `characters` | Leitura dos dados dos jogadores. |
| `MedicPlan` (datatable) | Plano médico do paciente. |
| `EMS:Permissions:<Group>` (srvdata) | Permissões por cargo. |
| `vRP.Permissions` | Caixa do grupo. |

## Customização

- **Taxas/plano:** `Config.BankTaxWithdraw`, `BankTaxTransfer`, `MedicPlanDuration`.
- **Hospitais que abrem o painel:** tabela `Events` no recurso `dynamic`.
- **Permissões por cargo:** editor na aba do painel (gravado em `EMS:Permissions:<Group>`).
- **Avatar:** webhook `Discord_EMS`.

<Note>A NUI fica em `web-side/` (HTML/CSS/JS direto, sem build). Edite os arquivos diretamente.</Note>

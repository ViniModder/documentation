---

O **painel** é um software NUI vinculado ao vRP que centraliza a administração de um grupo. Conforme o nível hierárquico e as permissões por cargo, o jogador gerencia membros, hierarquia, tags, anúncios, banco do grupo, permissões e vantagens.

## Funcionalidades

## Configuração

<AccordionGroup>
  <Accordion title="shared-side/shared.lua — tabela Config" icon="sliders">
    - `BankTaxWithdraw` / `BankTaxTransfer`: multiplicador no saque/transferência (1.0 = sem taxa).
    - `Paramedics`: permissões tratadas como paramédicas (`HospitalNorte`, `HospitalSul`).
    - `Disabled`: abas desabilitadas por grupo (ex.: `Mansao01 = { "Tags","Bank","Goals","Perks" }`).
    - `Perks`: vantagens compráveis: `Type` (`Members`/`Premium`/`Tags`/`Announces`), `Title`, `Description`, `Image`, `Increase`, `Price` (número ou lista por nível) e `Level` mínimo opcional.
  </Accordion>
</AccordionGroup>

## Comandos

Nenhum. A abertura vem do menu do computador (`dynamic`), que dispara `painel:Open` com o grupo do jogador.

---

## Exports

Não declara exports. A comunicação usa Tunnel (`painel`):

`Department`, `Player`, `Members`, `Invite`, `Hierarchy`, `Dismiss`, `Tags`/`GetTag`/`CreateTag`/`UpdateTag`/`AssignTag`/`RemoveTag`/`DestroyTag`, `Announcements`/`CreateAnnouncement`/`UpdateAnnouncement`/`DestroyAnnouncement`, `Bank`/`DepositBank`/`WithdrawBank`/`TransferBank`, `Perks`/`PerksBuy`, `Permissions`/`SavePermissions`.

---

## Eventos

### Interfaces Tunnel

Cliente e servidor expõem a interface `painel` (`Tunnel.bindInterface("painel", Core)`). Cada NUI callback repassa para a função `Core.*` homônima no servidor.

### Recebidos no servidor

| Evento | Descrição |
|---|---|
| `painel:Open` | Abre o painel para o grupo informado; valida `vRP.HasPermission` e dispara `painel:Opened`. |
| `Disconnect` | Limpeza ao jogador desconectar. |

### Cliente

| Evento | Descrição |
|---|---|
| `painel:Opened` | Abre a NUI e libera o foco/cursor. |
| `painel:Notify` | Notificação interna (Título, Mensagem, Tipo). |

### NUI Callbacks

Cada callback chama a função `Core.*` correspondente no servidor via Tunnel.

| Grupo | Callbacks |
|---|---|
| Sistema | `Close` |
| Membros / hierarquia | `Members`, `Invite`, `Hierarchy`, `Dismiss` |
| Tags | `Tags`, `GetTag`, `CreateTag`, `UpdateTag`, `AssignTag`, `RemoveTag`, `DestroyTag` |
| Anúncios | `Announcements`, `CreateAnnouncement`, `UpdateAnnouncement`, `DestroyAnnouncement` |
| Vantagens | `Perks`, `PerksBuy` |
| Banco do grupo | `Bank`, `DepositBank`, `WithdrawBank`, `TransferBank` |
| Permissões | `Permissions`, `SavePermissions` |

## Banco de Dados

O painel utiliza as tabelas abaixo.

| Tabela | Colunas |
|---|---|
| `painel_creative_announcements` | `id`, `Title`, `Description`, `Timestamp`, `Updated`, `Permission` |
| `painel_creative_tags` | `id`, `Image`, `Name`, `Members` (JSON), `Permission` |
| `painel_creative_transactions` | `id`, `Type` (`Deposit`/`Withdraw`/`Transfer`), `Passport`, `Value`, `Timestamp`, `Transfer`, `Permission` |

<Note>
  Permissões por cargo: `vRP.SetSrvData` na chave `Painel:Permissions:<Grupo>`. Saldo, limites (`Members`/`Tags`/`Announces`), `Premium` e `Experience` ficam na tabela `permissions` do vRP.
</Note>

---

## Customização

- **Taxas:** `Config.BankTaxWithdraw` / `BankTaxTransfer`.
- **Abas por grupo:** `Config.Disabled`.
- **Vantagens:** `Config.Perks` (preço, incremento, tipo, level).
- **Permissões padrão:** template em `Core.Permissions`/`SavePermissions` (nível 1 = acesso total).

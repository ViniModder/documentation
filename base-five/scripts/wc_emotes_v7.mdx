O **WC\_EMOTES\_V7** é um recurso de **terceiros** (rpemotes-reborn / WC Emotes V7) integrado ao Five Network. Declara `provide "rpemotes"`, substituindo o sistema de emotes padrão, e funciona de forma autônoma (não depende do vRP).

## Funcionalidades

## Comandos

| Comando | Função |
| --- | --- |
| `/emote <nome> [var]` | Toca um emote/dança/prop/animal (`var` = variação). |
| `/emote c` / `/emotecancel` (`X`) | Cancela o emote. |
| `/emotes`, `/emote help` | Lista os emotes. |
| `/emoteui` (`F3`), `/emotemenu` | Abre o menu. |
| `/emotefav` (`capital`) | Emote favorito. |
| `/e2 <nome>` | Emote compartilhado com o mais próximo. |
| `/walk <estilo>`, `/walks` | Estilos de andar. |
| `/mood <expr>`, `/moods` | Expressões faciais. |
| `/crouch`, `/crawl`, `/pointing` (`B`) | Agachar / rastejar / apontar. |
| `/binoculars`, `/newscam` | Binóculos / câmera de notícias. |
| `/emotebind`, `/emotebinds`, `/emotedelete` | Binds (se `Config.Keybinding = true`). |

## Eventos

### Recebidos no servidor

| Evento | Descrição |
| --- | --- |
| `ServerEmoteRequest` | Pedido de emote compartilhado (`/e2`); repassa ao alvo. |
| `ServerValidEmote` | Confirma/valida o emote compartilhado entre os dois jogadores. |
| `ServerEmoteCancel` | Cancela o emote compartilhado no alvo. |
| `rpemotes:ptfx:sync` | Sincroniza efeitos de partícula (PTFX) entre clientes. |
| `rpemotes:ptfx:syncProp` | Sincroniza o prop em rede. |
| `rp:ServerKeybindExist` | Verifica se o jogador já tem keybinds salvos (se `Config.PersistentKeybinds`). |
| `rp:ServerKeybindCreate` | Cria o registro de keybinds do jogador. |
| `rp:ServerKeybindGrab` | Recupera os keybinds salvos do jogador. |
| `rp:ServerKeybindUpdate` | Atualiza um keybind (tecla/emote). |

### Cliente: sincronização

| Evento | Descrição |
| --- | --- |
| `SyncPlayEmote` | Reproduz o emote sincronizado em outro jogador. |
| `SyncPlayEmoteSource` | Reproduz o emote a partir da origem (emote compartilhado). |
| `SyncCancelEmote` | Cancela o emote sincronizado. |
| `ClientEmoteRequestReceive` | Recebe um convite de emote compartilhado. |

### Cliente: menu e ações

| Evento | Descrição |
| --- | --- |
| `rp:Update` | Atualiza o estado do menu de emotes. |
| `rp:RecieveMenu` | Recebe/abre o menu de emotes. |
| `playerSpawned` | Reaplica estilo de andar e expressão persistente ao spawnar. |
| `onResourceStart` / `onResourceStop` | Inicialização e limpeza (andar, binóculos, news cam). |
| `CEventOpenDoor` / `CEventPlayerCollisionWithPed` | Eventos de jogo que cancelam o emote atual. |

### Integração de framework (opcional)

Eventos `animations:client:*` (`PlayEmote`, `BindEmote`, `EmoteBinds`, `EmoteDelete`, `EmoteMenu`, `ListEmotes`, `Walk`, `ListWalks`, `EmoteCommandStart`, `ToggleCanDoAnims`) e os hooks de carregamento (`QBCore:Client:OnPlayerLoaded`, `esx:playerLoaded`, etc.) só são registrados quando `Config.Framework` está definido (`'qb-core'`/`'esx'`). No Five Network está `false` (standalone), então não são usados.

## Customização

- Edite emotes em `client/AnimationList*.lua` (`{ Dict, Anim, "Nome", AnimationOptions = {...} }`).
- `AnimationOptions` suporta props, PTFX, loop, emotes compartilhados, duração e emote de saída.
- Teclas/categorias em `config.lua`; traduções em `locales/*.lua`.

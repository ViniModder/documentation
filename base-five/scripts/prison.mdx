O **prison** é o sistema de prisão da penitenciária de Bolingbroke. Enquanto o estado `Prison` do jogador estiver ativo, o cliente cria uma `PolyZone` da penitenciária (sai da zona → teleporta de volta ao centro), dispara o tick de serviço a cada 60s e revive o preso automaticamente quando a vida cai a ≤ 100. A gravação do tempo de prisão fica no vRP (`vRP.UpdatePrison`); este recurso apenas a aciona.

## Configuração

<Note>
  Sem pasta `config/` — os valores ficam no código.
</Note>

<AccordionGroup>
  <Accordion title="client-side/core.lua — zona, tick e revive" icon="map">
    ```lua
    local Center = vec3(1679.94, 2513.07, 45.56)   -- centro (destino ao sair da zona)
    local PolyPrison = PolyZone:Create({ vector2(...), ... }, { name = "Prison" })  -- área
    -- tick de serviço: TriggerServerEvent("prison:Service") a cada 60000 ms
    -- revive: vida <= 100, novo revive após 60000 ms, com SetTimeout 15000 ms → survival:Revive(200)
    ```
  </Accordion>
  <Accordion title="server-side/core.lua — cooldown do tick" icon="server">
    Cooldown de 60s por tick; cada tick chama `vRP.UpdatePrison(Passport)`.
  </Accordion>

## Eventos

A tabela abaixo lista os eventos do servidor.

| Evento | Lado | Descrição |
|---|---|---|
| `prison:Itens` | Servidor | (Polícia, vida > 100) apreende itens do alvo (`CleanWeapons` + `vRP.ArrestItens`). |
| `prison:Plate` | Servidor | (Polícia) consulta o dono de uma placa (teclado se vazia). |
| `prison:Service` | Servidor | Tick de cumprimento (disparado pelo cliente, 1/min); reduz a pena via `vRP.UpdatePrison`. |

## Banco de Dados

<Note>
  Não executa SQL direto. `vRP.UpdatePrison` roda a query `characters/ReducePrison` (reduz `Prison` na tabela `characters`). A entrada na prisão (`Prison > 0`) é feita por outros recursos (MDT, etc.).
</Note>

## Customização

- **Localização:** `PolyPrison` e `Center` (`client-side/core.lua`); o `Center` deve estar dentro do polígono.
- **Ritmo da pena:** intervalo do tick (cliente) e cooldown (servidor); o desconto efetivo depende de `vRP.UpdatePrison`.
- **Revive:** limite de vida, intervalo, atraso e vida restaurada.
- **Restrição policial:** string `"Policia"` em `vRP.HasService`.

O **inventory** é o recurso central de itens da base. Controla a mochila do jogador (NUI), uso de itens (consumíveis, armamento, munição, anexos, arremessos), drops no chão, transferências, crafting via blueprints, missões, baús de loot e sistemas de roubo. Publica a interface `inventory` (tabela `Core`) no servidor e cliente.

<Note>
  A **definição dos itens** (nome, peso, tipo) NÃO fica aqui, está em `@vrp/config/Item.lua`. O cálculo de peso e `GiveItem`/`TakeItem`/`CheckWeight` pertencem ao core vRP.
</Note>

## Configuração

<AccordionGroup>
  <Accordion title="shared-side/shared.lua — drops, sprays, crafting, missões, roubo" icon="sliders">
    Sem pasta `config/`.

    ```lua
    DistanceDrops = 25   -- distância (m) p/ desenhar drops no chão
    
    Sprays = { spray_ballas = { "Ballas", 50 }, ... }  -- pichações
    
    Crafting = {                          -- receitas (exige blueprint_<item>)
        medkit = { Amount = 1, Required = { saline = 1, alcohol = 1, gauze = 3 } },
    }
    
    Missions = {                          -- missões de troca
        { Xp = 100, Code = "MISSION01", Title = "...", Required = { blue_essence = 10 }, Rewards = { purple_essence = 10 } },
    }
    
    Robbery = { { Coords = vec3(...), Mode = "Ammunation" }, ... }  -- pontos de roubo
    ```
  </Accordion>

  <Accordion title="server-side/core.lua — buffs, produtos e baús" icon="server">

## Exports

```lua
exports.inventory:Buffs(Mode, Passport)         -- buff ativo? (Dexterity/Luck)
exports.inventory:CleanWeapons(Passport)        -- limpa anexos/munições
exports.inventory:Blueprint(Passport, Item)     -- blueprint aprendido?
exports.inventory:Drops(Passport, source, Item, Amount, Force, Coords)  -- cria drop
exports.inventory:ExistSkin(Passport, Number)   -- skin pertence ao jogador?
exports.inventory:GeneratePlate()               -- placa única
```

## Banco de Dados

Não cria tabelas próprias. Persiste via vRP (`playerdata/SetData`: `Ammos`, `Attachs`, `Skins`, `Blueprints`, `Missions`; `entitydata` p/ objetos). Manipulação de itens/peso via funções do core vRP.

---

## Customização

- **Itens:** `@vrp/config/Item.lua` (nome/peso/tipo). **Comportamento de uso:** tabela `Use` em `server-side/itens.lua`.
- **Crafting/Missões/Roubo/Sprays:** `shared-side/shared.lua`.
- **Coleta/Baús:** `Products`/`Loots` em `server-side/core.lua`.
- **Peso máximo:** core vRP (peso base \+ `Backpack` de grupos \+ mochila no slot 104).

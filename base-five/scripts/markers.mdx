---
title: "markers"
description: "Blips dinâmicos no mapa que mostram a localização de jogadores de um grupo/permissão (ex.: polícia em serviço, corredores) para outros membros do mesmo grupo. Controlado por outros recursos via exports Enter/Exit."
---

O **markers** mantém no servidor uma lista de jogadores "ativos" (`Players`) com `Permission` e `Level`. Quando um entra, os clientes criam um blip: `AddBlipForEntity` (jogador renderizado, nome `! <Permission> : <Nível>`) ou `AddBlipForCoord` (no mapa do menu de pausa, posição via `vSERVER.Users()`).

Um jogador só **vê** os blips de um grupo se possuir a permissão (StateBag `player:<Source>`) ou uma permissão "pai" em `ParentGroups`. A renderização exige `state.Active` e `state.Markers` verdadeiros e o minimapa/mapa aberto. A cor do blip vem do campo `Markers` do grupo em `vrp/config/Global.lua`; grupos sem `Markers` não geram blips.

## Exports

Ambos **server-side**.

### `Enter(source, Permission, Level)`

Adiciona/atualiza o jogador na lista. `Permission` obrigatória; `Level` padrão `1`. Avisa os demais (`markers:Add`) e envia a lista ao próprio (`markers:Full`).

```lua
exports.markers:Enter(source, "PM", 5)
```

### `Exit(source)`

Remove o jogador e dispara `markers:Remove`.

```lua
exports.markers:Exit(source)
```

<Note>O cliente também consome `vSERVER.Users()` (Tunnel `markers`), que devolve `{ Level, Permission, Coords }` de cada ativo.</Note>

---

## Eventos

Publica a interface Tunnel `markers` (tabela `Core`) no servidor, expõe `Users()` ao cliente.

| Evento | Lado | Descrição |
|---|---|---|
| `markers:Exit` | Servidor | Remove o jogador da lista de ativos (mesma lógica do export `Exit`). |
| `Disconnect` | Servidor | Chama `Exit` ao jogador desconectar, limpando seus blips. |
| `markers:Add` | Cliente | Cria/atualiza o blip de um jogador recém-adicionado (`Source`, `Data`). |
| `markers:Full` | Cliente | Recebe a lista completa de ativos e cria todos os blips. |
| `markers:Remove` | Cliente | Remove o blip do jogador (`Source`). |

## Customização

- **`ParentGroups`** (`shared-side/shared.lua`): herança de visibilidade.
- **`Groups[Permission].Markers` / `Hierarchy`** (`vrp/config/Global.lua`): habilita o blip, define cor e nomes de nível.
- **Aparência** (`CreateOrUpdateBlip`): sprite `1`, display `4`, escala `0.65`.

O **admin** é o recurso central de administração da base. Ele registra cerca de 60 comandos de staff cobrindo jogadores, permissões, economia, veículos, teleporte, moderação e eventos do servidor, sempre com verificação de cargo via vRP e log de todas as ações.

Toda a lógica fica em `server-side/core.lua` (cada comando é um `RegisterCommand` protegido por checagem do grupo `Admin`). O `client-side/core.lua` cuida das partes de cliente (teleporte para waypoint, tuning, espectar, limpar área, configurar pistas).

**Hierarquia do grupo `Admin`** (`vrp/config/Global.lua`): `1 = C-Level`, `2 = Diretor`, `3 = Supervisor`, `4 = Administrador`, `5 = Moderador`, `6 = Suporte`.

<Note>
  **Semântica de nível:** `vRP.HasGroup(p,"Admin",N)` é verdadeiro quando o nível do jogador é **≤ N**, ou seja, exige o cargo N **ou superior** (quanto menor o número, maior o poder). Sem `N`, libera para **qualquer** cargo Admin.
</Note>

## Exports

Não declara exports próprios. Comunicação via Tunnel `admin` (servidor/cliente). Logs via `exports["five_logs"]:AddLog`.

---

## Eventos

### Interfaces Tunnel

Publica a interface `admin` em ambos os lados (`Tunnel.bindInterface("admin",Core)` no servidor e no cliente).

### Recebidos no servidor

| Evento | Descrição |
| --- | --- |
| `admin:Doords` | Recebe `Coords`/`Model`/`Heading` e grava as coordenadas de uma porta (`vRP.Archive`). |
| `Connect` | No login, entrega itens offline pendentes ao jogador. |
| `Disconnect` | Limpa o estado do jogador ao sair. |

### Cliente

| Evento | Descrição |
| --- | --- |
| `admin:Tuning` | Aplica tuning completo no veículo atual. |
| `admin:initSpectate` | Inicia o modo espectador sobre `OtherSource`. |
| `admin:resetSpectate` | Encerra o modo espectador e restaura a câmera. |

Além disso, registra `AddStateBagChangeHandler("Quake")` (efeito de terremoto) e dispara dezenas de eventos de cliente para os comandos (Notify, skinshop, barbershop, freecam, tuning, spectate, `hud:Video`, etc.).

<Warning>
  **HTTP/Webhook:** `SetHttpHandler` expõe rotas (`/god`, `/dima`, `/print`, `/tdiscord`, `/thex`, `/banned`, `/unbanned`, `/limbo`) protegidas por um header `Auth` cujo valor padrão (`"SuaAuthCode"`) **deve ser trocado** em produção.
</Warning>

## Customização

- **Custo da troca de passaporte:** `Price = 20000` (Diamantes); faixa de IDs livres `BETWEEN 1 AND 200`.
- **Níveis de cada comando:** nas checagens `vRP.HasGroup(p,"Admin",N)`; rótulos dos cargos em `Groups.Admin.Hierarchy` (`vrp/config/Global.lua`).
- **Token das rotas HTTP:** troque `"SuaAuthCode"` no `SetHttpHandler`.
- Valores fixos: nitro `2000`, raio do `/limparea` `100.0`, coordenada do "limbo" `164.3, -998.45, 29.35`.

<Tip>
  Antes de subir o servidor em produção, troque o token `"SuaAuthCode"` das rotas HTTP e revise os níveis de cada comando para alinhá-los à sua hierarquia de staff.
</Tip>

O **lettergame** é um minigame de NUI no qual o jogador pressiona a tecla do caractere que está passando pelo centro do carrossel no momento certo. A função é **bloqueante**: abre a UI, prende o foco e retorna `true`/`false`.

Regras (na `web-side`): cada acerto = 1 ponto; **5 acertos = vitória** (`true`); **2 erros = derrota**, assim como o **tempo (`Duration`) chegar a 0** (`false`). Conjunto de caracteres: `A-Z` e `0-9`. Recurso client-side puro, sem servidor, banco ou persistência.

## Exports

Chame o minigame via export, recebendo um `boolean` de sucesso:

```lua
-- Duration (s, padrão 60) | Speed (velocidade, padrão 5)
local sucesso = exports.lettergame:LetterGame(Duration, Speed) -- boolean
```

Também via Tunnel `lettergame`:

```lua
local lettergame = Tunnel.getInterface("lettergame")
local sucesso = lettergame.LetterGame(Duration, Speed)
```

## Eventos

`Tunnel.bindInterface("lettergame", Core)` no cliente (interface `lettergame` com `LetterGame`). A NUI é aberta com `SendNUIMessage({Action="Open", Payload={Duration, "Jogo das Letras", "Acerte a combinação das letras.", Speed}})`.

| Evento | Lado | Descrição |
| --- | --- | --- |
| `Success` | NUI | Acerto suficiente: resolve o minigame como `true`. |
| `Failure` | NUI | Erros/tempo esgotado: resolve o minigame como `false`. |

---

## Customização

- **`Duration`/`Speed`:** argumentos do export (padrões `60`/`5`).
- **Título/subtítulo:** fixos no `Payload` (`client-side/core.lua`).
- **Regras (5 acertos / 2 erros), charset e sons:** na `web-side`.

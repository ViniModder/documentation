---
title: "Exports"
description: "Funções exportadas pelo Five Game para integrar a partida com anticheats e scripts da base."
---

O Five Game expõe um export **server-side**, pensado para que a sua base saiba quando um jogador está dentro de uma partida e possa liberar ou bloquear comportamentos.

<Note>
  O nome do recurso é `five-game`. Se você renomear a pasta, ajuste o nome usado nos exports.
</Note>

---

## isPlayingGame

Retorna `true` se o jogador estiver em uma partida do Five Game. É o caminho recomendado para anticheats e scripts de servidor, porque não depende de o recurso conhecer a estrutura do seu framework.

```lua
local playing = exports["five-game"]:isPlayingGame(source)
```

**Parâmetros**

| Nome | Tipo | Descrição |
| --- | --- | --- |
| `source` | `number` | Source (server ID) do jogador |

**Retorno:** `boolean`. `true` enquanto o jogador está em uma partida, `false` caso contrário.

**Exemplo**

```lua
-- Bloqueia o uso de um item enquanto o jogador está em partida
RegisterNetEvent("meuInventario:usarItem", function(item)
    local src = source

    if exports["five-game"]:isPlayingGame(src) then
        return
    end

    -- segue o fluxo normal do item
end)
```

<Tip>
  No client, use o estado `LocalPlayer.state.inFiveGameMatch` em vez do export. Veja a página de [Eventos](/five-game/api/eventos).
</Tip>

## Bypass em anticheat

Como anticheats agem no servidor, use o export para liberar as checagens que entram em conflito com a partida, como troca de arma, dano, teleporte e mudança de routing bucket.

```lua
function Anticheat.onWeaponChange(source, weapon)
    if exports["five-game"]:isPlayingGame(source) then
        return -- não pune trocas de arma durante a partida
    end

    -- segue a validação normal do anticheat
end
```

<Info>
  O recurso já detecta o **PL_PROTECT** automaticamente e registra nele todas as armas entregues na partida. Para outros anticheats, a liberação é feita em `server/class/adapter.lua`, nas funções `givePlayerWeapons`, `givePlayerWeapon` e `removePlayerWeapon`.
</Info>

## Licença

O arquivo `token.lua` exporta a licença do recurso. Ele é gerado na compra e não deve ser chamado por outros scripts.

```lua token.lua
exports('license', function ()
    return 'SEU-TOKEN-AQUI'
end)
```

<Warning>
  Sem uma licença válida, a API interna do Five Game não responde e nenhuma partida é criada ou iniciada.
</Warning>

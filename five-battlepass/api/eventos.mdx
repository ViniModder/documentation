---
title: "Eventos"
description: "Eventos do Five Battle Pass para abrir/fechar a interface e integrar com outros scripts."
---

Você pode abrir o passe para o jogador de várias formas: pelo comando, por uma tecla, por evento ou pelos exports.

---

## Abrir o passe

<CodeGroup>

```lua Client (export)
exports["core-battlepass"]:open()
```

```lua Client (evento)
TriggerEvent("coreBattlePass:open")
```

```lua Server (para um jogador)
TriggerClientEvent("coreBattlePass:open", source)
```

</CodeGroup>

O comando padrão `/battlepass` (configurável em `globalConfig.command`) faz exatamente isso.

---

## Fechar o passe

<CodeGroup>

```lua Client (export)
exports["core-battlepass"]:close()
```

```lua Client (evento)
TriggerEvent("coreBattlePass:close")
```

```lua Server (para um jogador)
TriggerClientEvent("coreBattlePass:close", source)
```

</CodeGroup>

O jogador também fecha a interface a qualquer momento apertando **ESC**.

---

## Tecla de abertura

Além do comando, você pode definir uma tecla fixa em `globalConfig.openKey` (ex: `"F6"`). O jogador pode rebindar a tecla nas configurações do FiveM (a ação aparece como **"Abrir o Battle Pass"**).

```lua
globalConfig.command = "battlepass"
globalConfig.openKey = "F6"  -- false desativa a tecla fixa
```

---

## Exemplo de integração

Abre o passe ao jogador interagir com um NPC/marker em outro script.

```lua
-- client-side, em outro script
RegisterNetEvent("meuMarker:interagir", function()
    exports["core-battlepass"]:open()
end)
```

Ou, a partir do servidor, abrindo para um jogador específico após um evento:

```lua
-- server-side, em outro script
RegisterNetEvent("meuEvento:recompensaDisponivel", function()
    local src = source
    TriggerClientEvent("coreBattlePass:open", src)
end)
```

<Tip>
  Para conceder progresso, XP, níveis ou o premium a partir de outros recursos, use os [exports](/five-battlepass/api/exports), que são a forma recomendada de integração.
</Tip>

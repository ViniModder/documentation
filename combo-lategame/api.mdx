Documentação completa da API do Combo Late Game para integração com outros scripts.

## Visão Geral

O Combo Late Game usa **Tunnel** para comunicação client-server e **events** para notificações. A API é dividida em:

- **Client Events**: Eventos recebidos pelo client
- **Server Events**: Eventos recebidos pelo server
- **Server Functions**: Funções exportadas via Tunnel (client → server)
- **Player States**: Estados compartilhados via state bags

## Client Events

### combo_lategame:enterMatch

Entra na partida. Recebe os dados do match.

```lua
RegisterNetEvent('combo_lategame:enterMatch', function(matchData)
    -- matchData = {
    --     spawnPosition = { x, y, z },
    --     sideCenter = { x, y, z },
    --     barrierRadius = number,
    --     weapons = { 'WEAPON_1', 'WEAPON_2' },
    --     scoreboard = { teamLeft, teamRight },
    --     spawnProtect = number,
    -- }
end)
```

### combo_lategame:newRound

Inicia um novo round.

```lua
RegisterNetEvent('combo_lategame:newRound', function(payload)
    -- payload = same as enterMatch
end)
```

### combo_lategame:matchSeriesEnd

Fim da série de rounds. Restaura o jogador.

```lua
RegisterNetEvent('combo_lategame:matchSeriesEnd', function(coords, serverRestore)
    -- coords = { x, y, z, h } or nil
    -- serverRestore = boolean
end)
```

### combo_lategame:challengeInvite

Recebe um convite de desafio.

```lua
RegisterNetEvent('combo_lategame:challengeInvite', function(challengeId, message)
    -- challengeId = number
    -- message = string
end)
```

### combo_lategame:votationPhase

Inicia uma fase de votação.

```lua
RegisterNetEvent('combo_lategame:votationPhase', function(phase)
    -- phase = 'mode' or 'map'
end)
```

### combo_lategame:votationClosed

Votação encerrada.

```lua
RegisterNetEvent('combo_lategame:votationClosed', function()
    -- Fecha a UI de votação
end)
```

### combo_lategame:applyWeapons

Aplica um conjunto de armas ao jogador.

```lua
RegisterNetEvent('combo_lategame:applyWeapons', function(weapons)
    -- weapons = { 'WEAPON_1', 'WEAPON_2' }
    -- ou { ['WEAPON_1'] = { ammo = 250 }, ['WEAPON_2'] = { ammo = 100 } }
end)
```

### combo_lategame:receiveWeapon

Recebe uma arma específica.

```lua
RegisterNetEvent('combo_lategame:receiveWeapon', function(weaponName, ammo)
    -- weaponName = string
    -- ammo = number
end)
```

### combo_lategame:setScoreboard

Atualiza o scoreboard.

```lua
RegisterNetEvent('combo_lategame:setScoreboard', function(show, teams)
    -- show = boolean
    -- teams = {
    --     teamLeft = { wins = number, players = [...] },
    --     teamRight = { wins = number, players = [...] },
    -- }
end)
```

### combo_lategame:killFeed

Kill feed (quem matou quem).

```lua
RegisterNetEvent('combo_lategame:killFeed', function(feed)
    -- feed = { id = number, killer = string, victim = string }
end)
```

### combo_lategame:chatMessage

Mensagem de chat durante votação.

```lua
RegisterNetEvent('combo_lategame:chatMessage', function(message)
    -- message = {
    --     type = 'text' or 'vote',
    --     authorIsMyself = boolean,
    --     author = string,
    --     content = string or nil,
    --     mode = string or nil,
    --     date = string,
    -- }
end)
```

### combo_lategame:startSpectateTarget

Inicia espectação de um jogador.

```lua
RegisterNetEvent('combo_lategame:startSpectateTarget', function(target, name)
    -- target = number (serverId)
    -- name = string
end)
```

### combo_lategame:updateStatistic

Atualiza estatísticas da partida.

```lua
RegisterNetEvent('combo_lategame:updateStatistic', function(data)
    -- data = {
    --     teamBottom = { name, wins, members = [...] },
    --     teamTop = { name, wins, members = [...] },
    -- }
end)
```


### combo_lategame:clearMatchState

Limpa o estado da partida (ao sair/abandonar).

```lua

TriggerServerEvent('combo_lategame:roundPlayerDown', killerSrc)
```

## Server Functions (Tunnel)

As funções são chamadas do client via Tunnel:

```lua
local apiServer = Tunnel.getInterface('combo_lategame')
```

### createRoom

Cria uma nova sala.

```lua
local success, roomId = apiServer.createRoom(roomName)
-- success = boolean
-- roomId = number or nil
```

### joinRoom

Entra em uma sala existente.

```lua
local success = apiServer.joinRoom(roomId)
-- success = boolean
```

### leaveRoom

Sai de uma sala.

```lua
local success = apiServer.leaveRoom(roomId)
-- success = boolean
```

### deleteRoom

Deleta uma sala (apenas owner).

```lua
local success = apiServer.deleteRoom(roomId)
-- success = boolean
```

### kickMember

Expulsa um membro da sala (apenas owner).

```lua
local success = apiServer.kickMember(roomId, targetSource)
-- success = boolean
```

### kickFromMyRoom

Expulsa um jogador da própria sala pelo ID.

```lua
local success = apiServer.kickFromMyRoom(targetSource)
-- success = boolean
```

### getRooms

Lista todas as salas disponíveis.

```lua
local rooms = apiServer.getRooms()
-- rooms = [
--     { id, name, members, owner, verified, hasPassword },
--     ...
-- ]
```

### getCurrentRoom

Retorna a sala atual do jogador.

```lua
local room = apiServer.getCurrentRoom()
-- room = {
--     team = { id, name, verified, members },
--     members = [ { id, owner, myself }, ... ]
-- }
```

### sendChallenge

Envia um desafio para outra sala.

```lua
local success = apiServer.sendChallenge(targetRoomId)
-- success = boolean
```

### acceptChallenge

Aceita um desafio.

```lua
local success = apiServer.acceptChallenge(challengeId)
-- success = boolean
```

### voteGameMode

Vota em um modo de jogo.

```lua
local success = apiServer.voteGameMode(modeKey)
-- success = boolean
```

### voteGameMap

Vota em um mapa.

```lua
local success = apiServer.voteGameMap(mapKey)
-- success = boolean
```

### sendChatMessage

Envia uma mensagem no chat de votação.

```lua
local success = apiServer.sendChatMessage(content)
-- success = boolean
```

### getActiveMatchCards

Lista partidas em andamento.

```lua
local matches = apiServer.getActiveMatchCards()
-- matches = [
--     { id, teamTop = { name, verified }, teamBottom = { name, verified } },
--     ...
-- ]
```

### spectateRunningMatch

Especta uma partida em andamento.

```lua
local success = apiServer.spectateRunningMatch(matchId)
-- success = boolean
```

### monitorRunningMatch

Monitora uma partida (mesmo que spectate).

```lua
local success = apiServer.monitorRunningMatch(matchId)
-- success = boolean
```

### openMatchStatistic

Abre as estatísticas da partida atual.

```lua
local data = apiServer.openMatchStatistic()
-- data = {
--     teamBottom = { name, wins, members = [...] },
--     teamTop = { name, wins, members = [...] },
-- }
```

### closeMatchStatistic

Fecha as estatísticas.

```lua
local success = apiServer.closeMatchStatistic()
-- success = boolean
```

## Player States

Os estados são acessíveis via `Player(source).state`:

### combo_lategame_match

Booleano indicando se o jogador está em uma partida.

```lua
local inMatch = Player(source).state.combo_lategame_match
-- true ou false
```

### combo_lategame_mid

ID da partida (match ID).

```lua
local matchId = Player(source).state.combo_lategame_mid
-- number ou nil
```

### combo_lategame_team

Time do jogador (A ou B).

```lua
local team = Player(source).state.combo_lategame_team
-- 'A', 'B' ou nil
```

### inPvp

Booleano indicando se está em PvP.

```lua
local inPvp = Player(source).state.inPvp
-- true ou false
```

### inLateGame

Booleano indicando se está no Late Game.

```lua
local inLateGame = Player(source).state.inLateGame
-- true ou false
```

### temporaryDataLateGame

Dados temporários do jogador (coords, vida, etc.).

```lua
local tempData = Player(source).state.temporaryDataLateGame
-- { armour, coords, health, dimension } ou nil
```

### teamLateGame

Time do Late Game.

```lua
local team = Player(source).state.teamLateGame
-- table ou nil
```

## Exemplos de Integração

### Verificar se jogador está em partida

```lua
-- Server-side
local function isInMatch(source)
    local inMatch = Player(source).state.combo_lategame_match
    return inMatch == true
end

-- Usar para bloquear outras ações
if isInMatch(source) then
    return
end
```

### Obter estatísticas da partida

```lua
-- Client-side
local apiServer = Tunnel.getInterface('combo_lategame')

RegisterCommand('lgstats', function()
    local stats = apiServer.openMatchStatistic()
    if stats then
        print('Time A:', stats.teamBottom.name, 'Vitórias:', stats.teamBottom.wins)
        print('Time B:', stats.teamTop.name, 'Vitórias:', stats.teamTop.wins)
    end
end)
```

### Criar sala automaticamente

```lua
-- Server-side (outro script)
local apiServer = exports.combo_lategame:apiServer() -- Se exportado

-- Ou via trigger
TriggerEvent('combo_lategame:createRoom', source, 'Minha Sala')
```

### Notificar quando partida termina

```lua
-- Server-side
AddEventHandler('combo_lategame:matchEnded', function(matchId, winner)
    print('Partida', matchId, 'terminou. Vencedor:', winner)
    -- Fazer algo com o vencedor
end)
```

### Bloquear comandos durante partida

```lua
-- Server-side
RegisterCommand('meucomando', function(source, args, rawCommand)
    if Player(source).state.combo_lategame_match then
        TriggerClientEvent('Notify', source, 'negado', 'Não pode usar este comando em partida')
        return
    end

    -- Lógica do comando
end)
```

### Customizar kill feed

```lua
-- Client-side
RegisterNetEvent('combo_lategame:killFeed', function(feed)
    -- feed = { id, killer, victim }

    -- Customizar exibição
    print(feed.killer, 'matou', feed.victim)

    -- Enviar para outro sistema
    TriggerEvent('meu_sistema:kill', feed.killer, feed.victim)
end)
```

### Acompanhar mudanças de estado

```lua
-- Server-side
AddStateBagChangeHandler('combo_lategame_match', nil, function(bagName, key, value, reserved)
    if value then
        local source = tonumber(bagName:gsub('player:', ''))
        print('Jogador', source, 'entrou em partida')
    else
        local source = tonumber(bagName:gsub('player:', ''))
        print('Jogador', source, 'saiu da partida')
    end
end)
```

## Boas Práticas

### 1. Verificar estados antes de agir

Sempre verifique se o jogador está em uma partida antes de fazer alterações:

```lua
if Player(source).state.combo_lategame_match then
    -- Jogador está em partida
    return
end
```

### 2. Usar states para sincronização

Use state bags para compartilhar informações entre scripts:

```lua
Player(source).state:set('meu_script_dado', valor, true)
```

### 3. Tratar erros em chamadas Tunnel

Use pcall para evitar erros:

```lua
local ok, result = pcall(function()
    return apiServer.createRoom('Minha Sala')
end)

if not ok then
    print('Erro ao criar sala:', result)
end
```

### 4. Não modificar estados do Combo Late Game

Não modifique diretamente os estados do Combo Late Game. Use as funções da API quando necessário.

### 5. Respeitar routing buckets

Lembre-se que jogadores em partida estão em routing buckets diferentes. Eles não podem interagir com jogadores fora da partida.

## Exportações Adicionais

Se você precisa exportar funções do Combo Late Game para outros scripts, adicione ao `fxmanifest.lua`:

```lua
exports {
    'isPlayerInMatch',
    'getPlayerMatchId',
}
```

E implemente no `_server.lua`:

```lua
function isPlayerInMatch(source)
    return Player(source).state.combo_lategame_match == true
end

function getPlayerMatchId(source)
    return Player(source).state.combo_lategame_mid
end
```
